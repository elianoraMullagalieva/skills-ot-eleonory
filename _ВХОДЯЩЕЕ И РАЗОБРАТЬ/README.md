# Входящее и разобрать

Сюда сначала попадают новые скиллы, промпты и материалы. До публикации они проходят три проверки:

1. Понятно ли, какую задачу решает материал.
2. Есть ли у него корректная структура и `SKILL.md`.
3. Можно ли его распространять: без личных данных, клиентских файлов и чужих ассетов без лицензии.

После проверки материал переносится в один из разделов `01–08`.
