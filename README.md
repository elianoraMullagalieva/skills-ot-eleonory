# 🧩 Скиллы от Элианоры

Актуальная публичная core-библиотека **23 скиллов** для Claude Code: дизайн интерфейсов, вёрстка, SVG, генерация визуала, сайты и автоматизация.

> Внутри только рабочие скиллы. Архивы, внутренние базы знаний и непроверенные для распространения шрифты намеренно не включены.

## Быстрый старт

1. Скачайте репозиторий: **Code → Download ZIP** или клонируйте его через Git.
2. Откройте папку нужной категории в `skills/`.
3. Перетащите папку конкретного скилла в Claude Code и попросите: «Установи этот скилл».

```bash
git clone https://github.com/elianoraMullagalieva/skills-ot-eleonory.git
```

Например, для прозрачных субтитров берите папку:

```text
skills/montage-svg-typography/montazh-prozrachnaya-tipografika
```

## Каталог

| Категория | Что внутри |
| --- | --- |
| `design-ui` | Визуальный вкус, UI/UX, стили интерфейсов, аудит и редизайн. |
| `layout-animation` | Вёрстка и JavaScript/SVG-анимация. |
| `svg-motion` | SVG-объекты, иллюстрации, схемы и SVG-анимации. |
| `image-video-generation` | Nano Banana, Kling, бренд-визуалы и image-to-code. |
| `sites-forms-sales` | Формы, анкеты, лидогенерация и Telegram-боты. |
| `claude-code-automation` | Инструменты Claude Code и рабочие инструкции. |

## Важно

- Используйте каждый скилл вместе со всеми файлами внутри его папки.
- У разных инструментов и материалов могут быть собственные лицензии — всегда проверяйте условия перед коммерческим использованием.
- Для вопросов и обновлений используйте Issues этого репозитория.
