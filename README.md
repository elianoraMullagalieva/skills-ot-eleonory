# 🧩 Скиллы Эли Аноры

Открытая библиотека для Claude Code: дизайн, монтаж Reels, SVG, вёрстка, генерация визуала, сайты и автоматизация.

## Начни отсюда

1. Открой раздел под свою задачу ниже.
2. Выбери **конкретную папку скилла** — в ней всегда есть `SKILL.md` и нужные дополнительные файлы.
3. Скачай репозиторий через **Code → Download ZIP** или клонируй его.
4. Перетащи папку скилла в Claude Code и напиши: «Установи этот скилл и используй его в работе».

```bash
git clone https://github.com/elianoraMullagalieva/skills-ot-eleonory.git
```

## Шрифты

В разделе [01 — Монтаж, SVG и типографика](./01%20%E2%80%94%20%D0%9C%D0%9E%D0%9D%D0%A2%D0%90%D0%96%2C%20SVG%20%D0%98%20%D0%A2%D0%98%D0%9F%D0%9E%D0%93%D0%A0%D0%90%D0%A4%D0%98%D0%9A%D0%90) лежат исходные коллекции шрифтов, HTML-эталоны, видео и рендер-инструменты. Manrope и JetBrains Mono сопровождаются лицензиями OFL-1.1; для остальных материалов права на использование и распространение нужно проверять отдельно.

> Раздел монтажа синхронизирован с рабочей папкой Эли Аноры **целиком**: без сокращения файлов, видео, эталонов и шрифтов. Личные базы и проекты клиентов из других разделов по-прежнему не публикуются автоматически.

Собрано **Эли Анорой** для Дизайн Кэмпа.
