# 🎨 Скиллы от Элеоноры

Коллекция Claude Code скиллов для дизайна, вёрстки, генерации визуала и создания вирусного контента. Собрано и адаптировано Элеонорой (elianora) — часть написана с нуля под свои задачи, часть отобрана из лучших открытых источников.

> **Скилл** — это папка с файлом `SKILL.md`, которая учит Claude Code выполнять конкретную задачу по строгим правилам. Кладётся в `~/.claude/skills/` и вызывается автоматически или командой `/имя-скилла`.

## 🚀 Как установить

```bash
# скопировать нужный скилл в папку скиллов Claude Code
cp -R "имя-скилла" ~/.claude/skills/
```

Затем в Claude Code вызвать `/имя-скилла` или просто описать задачу — подходящий скилл подхватится сам.

## 📂 Каталог

### ✍️ Контент и Reels
| Скилл | Что делает |
|-------|-----------|
| `eli-voice-skill` | Пишет и редактирует тексты голосом Элеоноры — посты, сторис, рассылки, лендинги. *Авторский* |
| `script` | Сценарист Reels на основе 2-летнего опыта и эфиров Reels-клуба. *Авторский* |
| `storyboard` | Раскадровщик: из текста сценария (~60-70 сек) делает 5-8 сцен с репликами и движением. *Авторский* |
| `podacha` | Креативный визуальщик: из сценария выдаёт 4-5 визуальных концепций подачи. *Авторский* |
| `eli-reels-graphics` | Единое ТЗ на графику/анимацию для Reels (типографика, инфографика, темп). *Авторский* |
| `research` | Поиск вирусных видео по теме на 8 языках (YT/Shorts/IG) для основы сценариев. *Авторский* |
| `discover` | Сканер outlier-контента в нише клиента за период. *Авторский* |
| `strategy` | Стратег Instagram-блога — проводит по методологии стратегии. *Авторский* |
| `cover` | Дизайнер обложек для Reels — выдаёт промт для GPT-Image/MJ. *Авторский* |
