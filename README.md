# 🎨 Скиллы от Элеоноры

Коллекция Claude Code скиллов для дизайна, вёрстки, генерации визуала и создания сайтов. Собрано и адаптировано Элеонорой (elianora) для студентов Дизайн Кэмпа.

> **Скилл** — это папка с файлом `SKILL.md`, которая учит Claude Code выполнять конкретную задачу по строгим правилам. Кладётся в `~/.claude/skills/` и вызывается автоматически или командой `/имя-скилла`.

## 🚀 Как установить

```bash
# клонировать весь репозиторий
git clone https://github.com/elianoraMullagalieva/skills-ot-eleonory.git

# скопировать нужный скилл в папку скиллов Claude Code
cp -R "имя-скилла" ~/.claude/skills/
```

Затем в Claude Code вызвать `/имя-скилла` или просто описать задачу — подходящий скилл подхватится сам.
