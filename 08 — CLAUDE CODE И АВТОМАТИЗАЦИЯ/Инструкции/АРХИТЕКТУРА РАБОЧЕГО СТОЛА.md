# Архитектура рабочего стола Эли

Карта помогает быстро находить нужные файлы. Структура построена 28 июня 2026.

## Корневой уровень `~/Desktop/`

```
Скиллы и Ассистенты/     ← все скиллы Claude и инструкции для GPT-ассистентов
Контент/                  ← посты, карусели, рефы, фотки ИИ
Портфолио/                ← все кейсы (личные + клиентские в одной куче)
Продукты/                 ← Дерзай в Дизайн + Дизайн Кэмп
Техничка/                 ← служебные программы, фрейм-кеты, скрипты Figma
Доки/                     ← документы для суда (НЕ трогать)
Yandex.Disk.2.app         ← приложение
_Разобрать (корень)/      ← старые скриншоты и неопределённые файлы
```

## Портфолио

Все кейсы (личные + клиентские) в одной папке, отсортированы по алфавиту.

```
Портфолио/
├── Александра балет/
├── Андрей Ель/                      ← пустая, заполнить когда найдётся
├── Бутово ТРЦ/
├── Дом Гирлянд/                     ← Desktop + Documents/Дом гирлянд кейс (объединено)
├── Замки Тёма/                      ← Documents/Замки Тёма + Documents/тема
├── Перформансы/                     ← Desktop/Перформансе + Documents/Ораторское
├── Полина юрист/                    ← polina-site + Documents/полина юрист
├── Роботы/
├── Тёма фотосессия/
└── _Обложки кейсов/                 ← MacBook-обложки и презентационные jpg
```

**Внутри каждого кейса единая структура** (где много файлов):
```
[Название кейса]/
├── 01 Логотипы и фир.стиль/
├── 02 Фото и рефы/
├── 03 Сайт (HTML и CSS)/
├── 04 Видео и анимации/
├── 05 Архивы (zip)/
├── 06 Документы (pdf, docx)/
└── 07 Исходники (psd, ai, fig)/
```

## Правила именования

- **Корневые папки** — коротко, без цифровых префиксов (`Контент`, `Портфолио`, `Продукты`)
- **Подпапки внутри кейсов** — с цифрами 01-07 для сортировки порядка (Логотипы → Фото → Сайт → Видео → Архивы → Документы → Исходники)
- **Папки в конец списка** — с подчёркиванием в начале (`_Разобрать`, `_Обложки кейсов`)

---

## Принципы организации Дизайн Кэмпа

Кэмп — отдельный мир. Чтобы не закапывать важные фото вглубь:
- **Фото черновики персонажей** — на верхнем уровне (без вложенности)
- **Видео персонажей** — на верхнем уровне
- **Итоговые фото** — на верхнем уровне
- **Рабочие фото** — на верхнем уровне
- **ТЗ и техника** (хостинг, версии сайта, шрифты, иконки ИИ) — собрано в одной папке
- **Брендбук** — отдельно (логотипы, шрифты, иконки финальные)

Всё что относится к контенту проекта — **сразу на виду в `Продукты/Дизайн Кэмп/`**.

## Ничего не удалено

Гарантировано:
- Все файлы перемещены, не удалены
- Movavi Library есть в `~/Movies/Movavi Library/` (её родное место)
- Если что-то не нашлось — проверь `_Разобрать (корень)/` или поищи через Spotlight

## Если что-то не нашлось

1. Файл попал в `_Разобрать (корень)/` или `Скиллы и Ассистенты/_Разобрать/`
2. Файл остался в `~/Documents/` (не разбирали)
3. Файл лежит внутри подпапки кейса в одной из 7 категорий
4. Используй Spotlight (Cmd+Space) или поиск в Finder
