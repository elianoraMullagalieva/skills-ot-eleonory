# 08 — Claude Code и автоматизация

В `Скиллы` лежат:

- `full-output-enforcement` — правила полного, а не обрезанного результата.
- `help-ru` — помощь и команды Codex на русском языке.

Этот раздел — для рабочих правил и автоматизации. Не добавляй сюда скиллы про дизайн или контент: для них уже есть тематические разделы.
