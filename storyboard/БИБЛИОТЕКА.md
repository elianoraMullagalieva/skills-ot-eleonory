# Библиотека персонажей и иконок

Здесь — готовые SVG-сниппеты, которые надо использовать как есть (с подстановкой координат). Один и тот же персонаж в разных роликах должен выглядеть одинаково — для этого библиотека.

## Как пользоваться

1. Найти нужного персонажа/иконку
2. Скопировать SVG-сниппет в кадр
3. Подставить координаты под композицию сцены (см. КОМПОЗИЦИЯ.md → размеры)
4. **Узнаваемую деталь не трогать** (свитер, очки, бейдж — это «лицо» персонажа)

Если нужного нет — нарисовать в стиле библиотеки и в конце `storyboard.md` отдать блок «дописать в БИБЛИОТЕКА.md».

## Как добавлять новых персонажей

В конце `storyboard.md` после раскадровки — блок:

```
📚 ДОПИСАТЬ В БИБЛИОТЕКА.md:

### [Название]

**Узнаваемая деталь**: [одна неизменная черта — то по чему персонаж узнаётся между роликами]
**Когда использовать**: [роли, контексты]
**Тип формы**: [закруглённые/острые/средние]

```svg
[готовый сниппет ~10-25 строк]
```
```

Уля сама решит — вставлять или нет. Если вставляет — этот персонаж становится канонным.
