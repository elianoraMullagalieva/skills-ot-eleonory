# 04 — Генерация изображений и видео

В `Скиллы` собраны:

- `brandkit` — брендовые визуальные системы.
- `image-to-code` — сайт по визуальному референсу.
- `imagegen-frontend-mobile` и `imagegen-frontend-web` — визуальное направление для интерфейсов.
- `kling-video` — промпты для Kling.
- `nano-banana-imagegen` — генерация и редактирование изображений в Nano Banana.

Перед генерацией зафиксируй задачу, стиль, формат и ограничения по бренду — это важнее длинного промпта.
