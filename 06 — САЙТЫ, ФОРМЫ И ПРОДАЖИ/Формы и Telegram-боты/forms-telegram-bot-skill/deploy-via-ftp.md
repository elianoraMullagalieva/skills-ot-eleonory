# Деплой формы на Beget через FTP

## Шаг 1. Создать отдельный FTP-аккаунт

⚠️ **Никогда не давай главный пароль Beget** для FTP-доступа. Создавай отдельный аккаунт для каждой задачи.

1. Зайди в Beget → раздел **Хостинг** → **FTP**
2. Логин: `elianora21_camp` (или любое имя, заканчивающееся на латиницу/цифры)
3. Пароль: нажми иконку 🪄 — Beget сгенерирует сам
4. **Путь к директории**: выбрать конкретную папку, например `/derzayvdesign.com/public_html/`
5. SSH **не включать**
6. Нажать **Добавить**

⚠️ Подчёркивание в логине только **между буквами**, не в начале и не в конце.

## Шаг 2. Залить файл через curl

```bash
FTP_HOST="elianora21.beget.tech"
FTP_USER="elianora21_camp"
FTP_PASS='ПАРОЛЬ_ЗДЕСЬ'

# Создать папку (если нужна)
curl -s --user "${FTP_USER}:${FTP_PASS}" "ftp://${FTP_HOST}/" -Q "MKD camp"

# Залить файл
curl -s --user "${FTP_USER}:${FTP_PASS}" \
  -T /path/to/anketa.html \
  "ftp://${FTP_HOST}/camp/index.html"

# Проверить что залилось
curl -s --user "${FTP_USER}:${FTP_PASS}" "ftp://${FTP_HOST}/camp/" --list-only
```

## Шаг 3. Учесть проксирование домена

### Проблема: derzayvdesign.com проксируется через ddos-guard → Tilda

У Эли основной сайт `derzayvdesign.com` идёт **не напрямую с Beget**, а проксируется через ddos-guard к Tilda. Поэтому если положить файл на Beget в папку `derzayvdesign.com/public_html/camp/index.html` — снаружи по адресу `https://derzayvdesign.com/camp/` он **не откроется** (404).

### Решения:

#### Вариант А: использовать тех-домен Beget
URL: `https://elianora21.beget.tech/derzayvdesign.com/camp/`

Минусы: длинный некрасивый URL.
Плюсы: работает мгновенно.
Решение для красивого URL: короткая ссылка через clck.ru / vk.cc / t.me.

#### Вариант Б: создать поддомен
1. Beget → **Домены** → добавить поддомен `camp.derzayvdesign.com`
2. Beget сам пропишет DNS и создаст папку
3. Залить файл в новую папку поддомена
4. URL: `https://camp.derzayvdesign.com` — красивый и работает

Минусы: нужно 5 минут на создание + 5–10 минут на распространение DNS.
Плюсы: солидный URL для постов и рассылок.

#### Вариант В: положить на другой домен
Если есть `yanadlx.ru` или другой свободный домен — кладём туда. Адрес типа `yanadlx.ru/anketa-camp/`.

## Шаг 4. Проверить что страница живая

```bash
curl -s -I "https://путь/к/странице/" -w "HTTP: %{http_code}\n"
```

Если 200 — всё ок.
Если 404 — папка не дошла до публичного веб-сервера, проверь путь и проксирование.

## Связь с Tilda

Если домен идёт через Tilda, **прямой деплой статичного HTML под основным доменом не работает**. В этом случае:
- Либо переносим форму **в саму Tilda через T123/Zero Block**
- Либо используем **поддомен** или **другой домен**

Решение зависит от ситуации.
