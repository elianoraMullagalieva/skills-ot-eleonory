# 01 — Монтаж, SVG и типографика

Раздел для Reels и моушена: от точных субтитров до SVG-инфографики, которую можно положить поверх видео.

## Скиллы Reels и моушен

- `montazh-prozrachnaya-tipografika` — синхронные субтитры и прозрачные текстовые оверлеи.
- `montazh-zagolovok-rvanyi` — ролики с выразительным заголовком и каскадом слов.
- `eli-reels-graphics` — графика в безопасной зоне вокруг talking-head видео.
- `premium-motion-infographics` — SVG/HTML-инфографика для сложных мыслей.

## SVG

- `svg-creator` — иконки, схемы, иллюстрации и SVG-объекты.
- `svg-animations` — движение SVG и анимационные сценарии.

## Шрифты

В папке `Шрифты/commercial-safe` лежат Manrope и JetBrains Mono с лицензиями OFL-1.1. Для остальных шрифтов всегда сначала проверяй права на коммерческое использование и распространение.
