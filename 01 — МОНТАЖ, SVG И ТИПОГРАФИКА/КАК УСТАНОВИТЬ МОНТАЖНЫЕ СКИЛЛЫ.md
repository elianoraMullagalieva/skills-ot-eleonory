# 🎬 Монтаж-скиллы Эли — перенос на новый ноутбук

Здесь всё, чтобы Claude Code на новом Mac умел делать твои монтажи так же (и лучше).

## ⭐ Самое главное (последние, лучшие наработки)
**`skills/montazh-prozrachnaya-tipografika`** — прозрачный субтитр-монтаж поверх твоего видео. Это финальный эталон:
- Типографика **Bebas + Gogol + оранжевый** (ты назвала «самый крутой монтаж»)
- Композиция: текст сверху / центр под тебя / dot-инфографика снизу
- **Прозрачный ProRes-экспорт** (кидаешь на дорожку, фон уже прозрачный) — скрипт `record_alpha2.py`
- Все выстраданные баги учтены: синхрон по словам, чипсы не «белыми кругами», НЕ фоновая dot-сетка (давала точки на весь экран), не терять фразы, не перезаписывать нарезанные файлы.

**`skills/premium-motion-infographics`** — дорогая смысловая SVG/HTML-инфографика для рилсов. Перед монтажом требует визуальный план, задаёт отдельный объект и движение для каждого смысла, запрещает повторяющиеся окна/галочки/бессмысленные линии и включает QA по безопасным полям, читабельности и вариативности.

## Установка на новом Mac (по шагам)

### 1. Скиллы → в Claude Code
```bash
mkdir -p ~/.claude/skills
cp -R skills/* ~/.claude/skills/
```
После этого Claude Code сам подхватит их, когда попросишь «сделай монтаж/субтитры».

### 2. Шрифты → в рабочую папку рилсов
```bash
mkdir -p ~/Documents/Reels-animations/_fonts
cp шрифты/* ~/Documents/Reels-animations/_fonts/
```
(Скилл ищет шрифты именно тут: `~/Documents/Reels-animations/_fonts/`.)
Опционально — установить в систему (двойной клик по .ttf → «Установить»).

### 3. Инструменты для рендера (нужны один раз)
```bash
# Python-библиотеки
pip3 install playwright
python3 -m playwright install chromium

# whisper для транскрибации речи (по секундам)
pip3 install mlx-whisper       # только для Apple Silicon (M1/M2/M3)

# ffmpeg (сборка видео)
brew install ffmpeg
```

### 4. Скрипты рендера — просто держи под рукой
Claude сам их пересоздаёт при работе, но можно скопировать:
```bash
cp скрипты-рендера/* ~/Documents/Reels-animations/
```

## Как этим пользоваться (напоминалка себе)
1. Записываешь говорящее видео.
2. Говоришь Claude: **«сделай субтитр-монтаж поверх этого видео»** + путь к файлу.
3. Claude: транскрибирует по секундам → раскладывает типографику → показывает HTML в браузере.
4. Ты смотришь, даёшь правки (в браузере, живьём).
5. Утверждаешь → Claude рендерит прозрачный `.mov`.
6. Кидаешь на дорожку в CapCut — **фон уже прозрачный**, режим смешивания не нужен.

## Важные правила (чтоб не наступать на грабли)
- **Прозрачный оверлей = фон СТРОГО пустой.** Никаких полупрозрачных фоновых сеток/дымки — они дают мусор-точки на весь экран при экспорте.
- **Не перезаписывать файл, который уже нарезала** — рушит монтаж. Новая версия = новое имя.
- Всё детально прописано в `skills/montazh-prozrachnaya-tipografika/SKILL.md` — Claude читает это сам.
