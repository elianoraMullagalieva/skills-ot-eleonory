# Elianora — premium motion visual system

## Locked semantic mapping

| Meaning | Visual object | Motion must communicate |
|---|---|---|
| Speech, transcription, timestamps | Sphere assembled from digits or glyphs | speech has volume; individual words can extract from the sphere |
| Claude Code, skills, code | ASCII/pixel object or pixel creature | code is parsed, sorted, compiled, or transformed; never use an invented mascot |
| Key phrases, selection, meaning | Dense 3D dot cloud or particle field | many inputs are filtered; selected words pull outward |
| Time, steps, speed, progress | Diagram built from circles, arcs, waves, hatching, counters | comparison, compression, cadence, sequence |
| Animation, editing, revisions | Asymmetrical graphic card with scene-specific geometry | clips align, layers snap, timing shifts, or edits are revised |
| A process / instruction | A trajectory that physically assembles the resulting object | cause becomes effect; no purposeless trailing path |

The preferred chain for a multi-step explanation is: **speech symbols gather into a sphere → important words are extracted as subtitles → tokens snap onto a timeline → a finished reel is assembled.**

## Graphic language

- Palette: black, white, and neutral grey. `#D35049` is rare: one active point, selected word, pulse, or branded micro-detail—not a default outline or repeated decoration.
- Build dimensionality through hundreds of small glyphs, dots, micro-labels, raster-free texture, density shifts, masking, and controlled parallax.
- Prefer asymmetric silhouettes, varying density, and crisp construction over generic rounded UI cards.
- Lines may be fine only when their function is explicit. They must draw an object, measure a relation, show a path, or tether data; never sit as decoration.
- Use 2–3 text sizes and one tiny technical label size. The reduced subtitle / metadata tone is visibly quieter than the title on both white and black backgrounds.

## Variation contract

For each scene write these five different values before coding:

1. **Silhouette** — e.g. globe, ASCII creature, radial chart, hatching field, cutaway timeline.
2. **Matter** — digits, words, dots, pixels, arcs, blocks, or strokes.
3. **Kinetic verb** — gather, filter, unfold, scan, snap, stack, slice, compress, or release.
4. **Information** — the exact thing a silent viewer should learn.
5. **Transition** — what physically becomes the next scene.

No two adjacent scenes may share more than one of these values. A repeated visual family later in the video needs a new semantic role and a new kinetic verb.

## Forbidden shortcuts

- Repeating a browser frame, generic panel, checkmark, node graph, circles-with-lines, or mascot pose across beats.
- Making a scene by changing only the title under the same animation.
- Giant icons, thick outlines, oversized controls, random paths, or diagrams that collide with their labels.
- A generic substitute for a supplied mascot, logo, font, or reference asset.
- Starting a full edit before the visual treatment and a proof scene are approved when the user requests a preview.

## Pre-delivery proof

At the target dimensions, capture each scene at: entrance, cause/effect moment, and exit. Reject and rebuild if there is clipping, a collision, a static hold without a live signal, unclear action, or a repeated silhouette. For a full reel, check a contact sheet before sending the preview link.
