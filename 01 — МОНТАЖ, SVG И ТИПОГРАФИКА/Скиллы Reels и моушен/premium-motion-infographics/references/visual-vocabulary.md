# Visual vocabulary

Use one object family per beat, then change the kinetic verb between beats.

| Meaning | Object | Kinetic verb | Avoid |
|---|---|---|---|
| Speech becomes structure | glyph sphere / word cloud | gather, rotate, extract | static text orbit |
| AI processes input | mascot + modular blocks | accept, sort, transform | mascot standing next to a panel |
| Faster workflow | compression chart / time blocks | fold, collapse, accelerate | generic progress bar |
| Caption timing | waveform + word tokens | snap, align, lock | unrelated node graph |
| Select important ideas | particle field / filters | sieve, pull, cluster | three identical chips |
| Leave composition space | crop map / protected field | reveal, reserve, frame | oversized borders |
| Review | diff stack / cursor / annotations | compare, replace, approve | giant checkmark |
| Final export | playback architecture | assemble, play, release | generic terminal window |

## High-end traits

- Let detail appear through systems: many small marks, timestamps, particles, glyphs, sliders or micro-labels that obey a grid.
- Pair one expressive object with a restrained information layer; do not make every element expressive.
- Let objects transform rather than disappear and reappear as unrelated shapes.
- Make visual complexity legible in stages: silhouette, internal pattern, then active signal.

## Anti-patterns

- One browser mockup or rounded rectangle repeated scene after scene.
- Decorative lines and dots that do not explain an operation.
- A large central icon standing still while a caption changes.
- Identical scale, position and easing in consecutive scenes.
- Accent-colour outlines, progress bars or giant checkmarks used as filler.
