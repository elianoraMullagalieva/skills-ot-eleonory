# Как запускать агентов параллельно

**Что это:** Способ делать несколько независимых задач одновременно через Claude, а не по очереди

**Когда использовать:** Когда есть 3+ независимые задачи и важно не ждать — например, параллельно готовить тексты, делать макеты и генерировать изображения

---

## Что такое агенты и зачем их запускать одновременно

Обычно Claude делает задачи по очереди: сначала одну, потом другую. Это нормально если задачи связаны.

Но если задачи независимые — нет смысла ждать. Claude может запустить несколько подзадач параллельно, каждая работает как отдельный поток. Это как нанять трёх помощников вместо одного.

Экономия времени реальная: три задачи по 5 минут — это 5 минут вместо 15.

---

## Когда это реально экономит время

Подходит когда задачи не зависят друг от друга:

- Написать текст для главного экрана + написать текст для раздела "о нас" + написать тексты для кнопок
- Сгенерировать три разных варианта логотипа
- Проверить типографику на трёх страницах Figma
- Собрать информацию о трёх разных конкурентах

Не подходит когда задача 2 зависит от результата задачи 1.

---

## Промпт для запуска параллельных агентов

```
Запусти столько агентов сколько нужно, параллельно:

Агент 1: напиши текст для главного экрана лендинга академии. 
Тон — живой, без клише. До 80 слов.

Агент 2: напиши текст для раздела "кому подходит". 
3 портрета аудитории, каждый 2-3 предложения.

Агент 3: напиши 5 вариантов заголовка для поп-апа с записью.
Каждый вариант — максимум 7 слов.

Жди пока все три закончат, потом покажи результаты вместе.
```

---

## Что каждый агент делает независимо

Каждый агент получает свою задачу и работает с ней как будто это единственная задача. Они не знают о существовании друг друга, не мешают друг другу.

Это значит:
- Каждый агент может использовать свои инструменты (Figma MCP, поиск, генерация)
- Если один агент упал — остальные продолжают работу
- Можно давать агентам разные роли: один как редактор, другой как дизайнер

---

## Как получить результаты от всех агентов

После запуска просто жди. Claude соберёт результаты когда все агенты закончат и покажет их вместе.

Если нужно контролировать процесс:

```
Запусти агентов параллельно. После каждого завершения сообщай кратко:
"Агент 1 готов: [первые 10 слов результата]"
Когда все готовы — покажи всё полностью
```

Если результат одного агента нужен другому — это уже не параллельная задача. Тогда делай цепочкой: сначала первый, потом второй с результатом первого.

---

## Лайфхаки и правила

- Нумеруй агентов — так легче давать обратную связь ("агент 2 хорош, агент 1 перепиши")
- Давай каждому агенту чёткий объём — "до 80 слов", "5 вариантов", не "напиши текст"
- Параллельная работа хорошо работает для вариативных задач — когда нужны три варианта чего-то, пусть три агента делают по одному варианту каждый
- Можно запускать агентов в Figma: один проверяет типографику, второй проверяет цвета, третий проверяет отступы

---

## Частые ошибки

- Запускать параллельно зависимые задачи — агент 2 начнёт работать без данных от агента 1 и сделает не то
- Не указывать объём задачи — агенты делают задачи разного масштаба и результаты не сравнимы
- Запускать больше 5-6 агентов сразу — становится сложно отследить, лучше группами
