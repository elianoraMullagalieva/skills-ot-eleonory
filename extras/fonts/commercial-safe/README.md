# Шрифты для студентов — коммерческое использование

В этой папке — только шрифты, которые можно использовать в коммерческих проектах и распространять вместе с их лицензиями.

## Что внутри

- `Manrope/` — заголовки и основной текст.
- `JetBrains Mono/` — технические акценты, цифры, короткие подписи и темы про AI/код.
- `Лицензии/` — полные тексты SIL Open Font License 1.1. Их нужно оставлять в комплекте при передаче папки студентам.

## Важно

- Шрифты можно использовать в коммерческих роликах, презентациях и дизайне.
- Не продавайте шрифты отдельно и не удаляйте файлы лицензий из набора.
- `BebasNeueCyrillic.ttf` и `Gogol-Regular.otf` лежат отдельно — в `../display/`: лицензии именно этих файлов пока не подтверждены, для коммерческих проектов проверь их сам.

Источники: [Manrope](https://www.sharanda.com/manrope), [JetBrains Mono](https://www.jetbrains.com/lp/mono/).
