# Шрифты Bebas Neue Cyrillic и Gogol — скачать отдельно

Эти два шрифта не входят в репозиторий: их лицензия на распространение не подтверждена.
Скачай их сам(а) с официальных страниц авторов/дистрибьюторов (поиск: «Bebas Neue Cyrillic font», «Gogol font»),
проверь лицензию для своего проекта и положи файлы с ТОЧНО такими именами:

- `BebasNeueCyrillic.ttf`
- `Gogol-Regular.otf`

в папку `fonts/` этого скилла (`~/.claude/skills/montazh-prozrachnaya-tipografika/fonts/`).
Без них эталон отрисуется запасными шрифтами (Manrope) — монтаж работает, но вид будет другой.
