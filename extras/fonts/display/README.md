# Акцидентные шрифты эталона монтажа

- `BebasNeueCyrillic.ttf` — узкий капс-гротеск для заголовков.
- `Gogol-Regular.otf` — рукописный акцент (1–2 слова).

Эти файлы нужны эталонным HTML и скиллу `montazh-prozrachnaya-tipografika` (там лежит своя копия в `fonts/`).
Лицензии именно этих файлов не подтверждены: для личных экспериментов — ок, перед коммерческим проектом проверь права у правообладателя или замени на шрифты из `../commercial-safe/` (Manrope, JetBrains Mono — OFL-1.1).


> **Шрифты Bebas Neue Cyrillic и Gogol не входят в комплект** (лицензия не подтверждена) — см. `fonts/СКАЧАТЬ_BEBAS_И_GOGOL.md`. Без них работает с запасным Manrope.
