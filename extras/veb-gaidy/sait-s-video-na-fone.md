# Как сделать сайт с видео на фоне (скролл-эффект)

**Что это:** Верстаешь HTML-страницу где фоновое видео "прилипает" к экрану пока пользователь скроллит вниз — контент едет, видео остаётся на месте. Это называется parallax или fixed background.

**Когда использовать:** Для портфолио, лендингов клиентов из креативных ниш, приветственных секций. Особенно круто смотрится у фотографов, студий, Performance Club, дизайн-академий. Не подходит для простых утилитарных сайтов — там это будет перебором.

---

## Промпт для Claude

```
Сверстай HTML-страницу с видео на фоне и скролл-эффектом. Вот детали:

СТРУКТУРА СТРАНИЦЫ:
1. Секция Hero (100vh):
   - Полноэкранное видео на фоне, зациклено, без звука, автовоспроизведение
   - Видео фиксированное (position: fixed) — не скроллится вместе со страницей
   - Поверх видео тёмный оверлей: rgba(0, 0, 0, 0.45)
   - По центру: заголовок белым шрифтом, подзаголовок серым, кнопка

2. Секция О нас (min-height: 100vh):
   - Белый фон, обычный контент
   - Появляется поверх видео при скролле — как будто наезжает на него

3. Секция Услуги (min-height: 80vh):
   - Светло-серый фон (#F5F5F5)

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:
- Видео-файл называется hero-bg.mp4, лежит в папке /video/
- Добавь запасной постер (poster="img/hero-poster.jpg") на случай если видео не загрузится
- На мобильных (экран меньше 768px): скрыть видео, показать статичную картинку hero-poster.jpg
- Шрифт: Inter из Google Fonts
- Анимация появления заголовка: fade-in + translateY снизу, 0.8s, при загрузке страницы
- Кнопка: hover-эффект с плавным переходом цвета 0.3s

ЦВЕТА:
- Акцентный: #C4A882
- Фон секций: белый и #F5F5F5
- Текст: #1A1A1A

Напиши чистый HTML в один файл (index.html) со встроенными CSS и JS. 
Без внешних библиотек кроме Google Fonts.
Добавь комментарии в код где что находится.
```

---

## Что происходит

Claude пишет один HTML-файл с видео в фоне через CSS-трюк: видео ставится `position: fixed` на весь экран, а секции с контентом едут поверх него с обычным `position: relative`. Когда белая секция "наезжает" на видео — создаётся иллюзия что видео остаётся на месте. Это работает в любом браузере без библиотек.

На мобильных автовоспроизведение видео заблокировано Safari и Chrome — поэтому Claude добавляет fallback: прячет видео через медиазапрос и показывает статичную картинку.

## Что нужно подготовить заранее

**Видео-файл (обязательно):**
- Формат: MP4 с кодеком H.264 — работает везде
- Размер: до 8 МБ. Больше — сайт будет грузиться медленно
- Разрешение: 1920×1080 или 1280×720 (не 4K — никто не заметит разницу, а вес огромный)
- Длина: 10–30 секунд, зациклится само
- Без звука (muted): обязательно, иначе браузер не запустит автовоспроизведение

Как сжать видео бесплатно: HandBrake (Mac/Win) или онлайн через Clideo.com

**Постер (желательно):**
- Первый кадр видео, сохранённый как JPG
- Размер: до 200 КБ
- Показывается пока видео грузится и на мобильных

**Структура папок до начала работы:**
```
мой-сайт/
  index.html        ← сюда Claude положит код
  video/
    hero-bg.mp4     ← твоё видео
  img/
    hero-poster.jpg ← постер (первый кадр)
```

## Чеклист проверки что всё работает

Открывай index.html в браузере и проверяй по шагам:

- [ ] Видео запустилось автоматически без нажатия
- [ ] Видео без звука (нет иконки звука в браузере)
- [ ] При скролле вниз — белая секция наезжает на видео, видео остаётся на месте
- [ ] Заголовок анимируется при загрузке страницы (плавно появляется снизу)
- [ ] Кнопка меняет цвет при наведении мыши
- [ ] Уменьши окно браузера до 375px ширины — видео скрылось, показалась картинка
- [ ] Текст поверх видео читается нормально (оверлей достаточно тёмный)

Если видео не запускается локально — открой файл через Live Server в VS Code или задеплой на Netlify (бесплатно, 2 минуты). Некоторые браузеры блокируют видео при открытии через file:///

## Лайфхаки и правила

**Видео цепляет только если оно хорошее.** Стоковое видео с пустыми руками или офисом выглядит дёшево. Лучше нейтральная абстракция (природа, текстуры, свет) или что-то брендовое. Higgsfield, Runway, Pika — для генерации видео под конкретный проект.

**Оверлей важнее чем кажется.** Без тёмного слоя поверх видео текст нечитаем. Начни с `rgba(0,0,0,0.5)`, потом подкрути под свой цвет бренда.

**Не делай всю страницу видео.** Видео в фоне — только для hero-секции. Дальше — обычные блоки с белым фоном. Если видео идёт через весь сайт — это утомляет.

## Частые ошибки

**"Видео не запускается"**
— Проверь что файл называется точно так же как в коде (hero-bg.mp4, без пробелов). Регистр важен: Hero-bg.mp4 и hero-bg.mp4 — разные файлы для Mac.

**"На мобиле видео всё равно показывается и не играет"**
— Значит медиазапрос не сработал. Попроси Claude: "убедись что на мобильных video { display: none } внутри @media (max-width: 768px)".

**"При скролле видео тоже едет вместе со страницей"**
— Значит видео не зафиксировано. Проверь в коде: у элемента video должно стоять `position: fixed`, не `absolute`.

**"Тормозит на слабом компьютере"**
— Видео слишком тяжёлое. Сожми через HandBrake: Preset → Web → Fast 720p30.
