# Скилл Эли — правила типографики в текстах

**Что это:** Базовые правила которые отделяют профессиональный текст от любительского

**Когда использовать:** Перед финальной сдачей макета клиенту, при проверке текстов в Figma, при написании контента для лендингов

---

## Правило 1: никакого КАПСА в заголовках

### Почему это выглядит дёшево

КАПСЛОК в заголовках — это наследие баннерной рекламы 2005 года. Глаза читают строчные буквы быстрее, потому что у них есть форма (асцендеры и десцендеры). КАПС — это одинаковые прямоугольники, мозг тратит больше усилий.

Кроме того, КАПС визуально "кричит". На лендинге всё кричит одновременно — и в итоге ничего не акцентировано.

### Плохо:
```
НАША АКАДЕМИЯ ПОМОГАЕТ ДИЗАЙНЕРАМ ВЫРАСТИ
ЗАПИШИСЬ СЕЙЧАС
```

### Хорошо:
```
Наша академия помогает дизайнерам вырасти
Запишись сейчас
```

### Когда капс ок:
- Аббревиатуры: ФНС, НДС, CEO
- Декоративный элемент в логотипе (но не в теле текста)
- Кнопки с одним-двумя словами в некоторых стилях UI

---

## Правило 2: никакой лесенки

### Что такое лесенка

Лесенка — когда каждая строка заголовка сильно короче предыдущей, и текст выглядит как треугольник или ступеньки.

### Плохо:
```
Как я запустила свою академию
и изменила подход
к дизайну
```

### Хорошо:
```
Как я запустила академию
и изменила подход к дизайну
```

Или перебить по смыслу:

```
Как я запустила академию —
и изменила подход к дизайну
```

### Как избежать

Переноси строки по смыслу, а не по ширине блока. Хорошая строфа — когда каждая строка заканчивается на смысловой паузе, а не обрывается на предлоге.

---

## Правило 3: висячие слова

### Что это

Висячее слово — последняя строка абзаца или заголовка, где стоит одно-два коротких слова в одиночестве.

### Плохо:
```
Мы создаём образовательные программы для тех,
кто хочет расти в дизайне и работать
с крутыми
клиентами
```

"с крутыми клиентами" — висит отдельно, разрушает ритм.

### Хорошо:
```
Мы создаём образовательные программы
для тех, кто хочет расти в дизайне
и работать с крутыми клиентами
```

### Как исправить

- Добавить или убрать слово чтобы последняя строка была весомой
- Переформулировать предложение
- Поменять ширину текстового блока в Figma (часто самое быстрое решение)

## Как просить Claude проверить типографику в Figma

Claude может читать текстовые слои через Figma MCP и проверять каждый из них.

**Промпт для проверки страницы:**

```
Прочитай все текстовые слои на странице [название страницы] в Figma.
Найди и перечисли:
1. Заголовки написанные КАПСОМ (кроме аббревиатур)
2. Заголовки с лесенкой — где каждая строка намного короче предыдущей
3. Абзацы с висячими словами — одно-два слова на последней строке
Для каждой проблемы: название слоя, текст, в чём проблема
```

**Промпт для исправления конкретного слоя:**

```
В слое [название слоя] есть лесенка.
Переформулируй текст чтобы строки были примерно одинаковой длины,
смысл сохрани
```

---

## Лайфхаки и правила

- Проверяй типографику на финальном размере экрана, не в 100% zoom Figma — висячие слова видны только на реальном масштабе
- Заголовки в 2-3 строки почти всегда дают лесенку — специально следи
- Предлоги в конце строки (на, в, с, и, а) — сигнал что перенос сделан неправильно
- Для русского текста правило висячих слов важнее чем для английского — у нас больше коротких слов

---

## Частые ошибки

- Исправить лесенку и получить висячее слово — проверяй сразу оба
- Убрать капс и не проверить регистр аббревиатур — ФНС нельзя писать Фнс
- Просить Claude проверить типографику без указания конкретной страницы — получишь общий ответ вместо конкретных слоёв
