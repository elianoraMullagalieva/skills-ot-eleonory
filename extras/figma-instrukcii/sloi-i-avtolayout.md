# Как переименовать слои и добавить автолаяут

**Что это:** Просишь Claude зайти в твой Figma-файл и навести порядок — правильные имена у слоёв, автолаяут с нормальными отступами.

**Когда использовать:** Когда у тебя хаос в слоях (Group 1, Frame 23, Rectangle 45) или когда нужно быстро добавить автолаяут к блокам, чтобы они тянулись как нормальные компоненты.

---

## Промпт для Claude

```
Открой мой Figma-файл [вставь ссылку на файл].

Сделай следующее:
1. Переименуй слои по правилу:
   - Фреймы страниц → hero / about / services / portfolio / contacts
   - Текстовые слои → heading, subheading, body, caption, label
   - Кнопки → btn-primary, btn-secondary
   - Иконки → icon-[название], например icon-arrow
   - Картинки → img-[описание], например img-hero-bg

2. Добавь автолаяут ко всем фреймам верхнего уровня:
   - Направление: вертикальное
   - Gap между элементами: 0
   - Padding: 0
   - Выравнивание: по центру по горизонтали

3. Для карточек внутри сеток:
   - Направление: вертикальное
   - Padding: 24px со всех сторон
   - Gap: 16px

Покажи список что переименовал перед тем как сохранить.
```

---

## Что происходит

Claude подключается к Figma через плагин, обходит все слои на текущей странице и переименовывает их по твоим правилам. Потом добавляет автолаяут к фреймам — они начинают работать как живые, тянуться при изменении контента.

На выходе ты получаешь список: "было — стало", чтобы проверить и при необходимости откатить.

---

## Лайфхаки и правила

**Называй слои по блокам сайта — это главное правило**

Структура имён должна отвечать на вопрос "где этот элемент и что он делает":

```
hero
  hero/heading
  hero/subheading
  hero/btn-primary
  hero/img-bg

about
  about/heading
  about/body
  about/img-team

services
  services/card (×3)
    services/card/icon
    services/card/heading
    services/card/body
```

Такие имена потом легко найти через Cmd+F в Figma, они нормально выглядят в хэндоффе разработчику, и Claude их понимает без объяснений.

**Автолаяут — не для всего.** Не добавляй его к декоративным элементам (волны, фигуры, фоны). Только к смысловым блокам и карточкам.

**Сначала переименовывай, потом делай компоненты.** Если сначала сделаешь компоненты с кривыми именами — придётся переименовывать в двух местах.

## Частые ошибки

**"Claude переименовал не те слои"**
— Укажи в промпте конкретную страницу: "работай только на странице 'Главная'", иначе он может пойти по всему файлу.

**"Автолаяут сломал верстку — всё съехало"**
— Это бывает если у фрейма были элементы с абсолютным позиционированием. Добавь в промпт: "если элементы внутри фрейма используют absolute position — не добавляй автолаяут к этому фрейму, пропусти его".

**"Не знаю как дать Claude доступ к Figma"**
— Нужен Figma MCP плагин. Он подключается через настройки Claude Code. Без него Claude видит Figma только по скриншоту, но не может редактировать файл.
