# STRUCTURE — шаблоны сценариев и формат вывода

Структура зависит от типа ролика. Сначала определяешь тип, потом выбираешь скелет.

---

## Три типа Reels (по цели)

### А. Охватный
- **Цель**: миллионы просмотров
- **Аудитория**: широкая, многие не подпишутся
- **Тема**: универсальная (отношения, деньги, тело, инфоповод)
- **Тон**: категоричный, провокационный, эмоциональный
- **Долженствование**: можно «притягивать за уши», утрировать

### Б. Прогрев к личности
- **Цель**: подписка на «вас», доверие к личности
- **Аудитория**: уже зацепившиеся за охват, теперь хотят знать про автора
- **Тема**: ваш путь, принципы, кейсы, ошибки, инсайты
- **Тон**: личный, честный, конкретный
- **Долженствование**: тезис + ВАШ опыт + что зритель из этого возьмёт

### В. Продающий
- **Цель**: записаться, купить, оставить заявку
- **Аудитория**: узкая, ваши потенциальные клиенты
- **Тема**: конкретная боль клиента + конкретное решение
- **Тон**: экспертный, спокойный, доказательный
- **Долженствование**: 1000 просмотров — это нормально, главное конверсия

## Универсальный скелет (база для всех типов)

```
[0-3 сек]   ХУК
            Крючок по одной из формул из HOOKS.md.
            Эмоция + движение + озвучка.

[3-7 сек]   КОНТЕКСТ
            Погружение: о чём вообще речь, кто герой, какая проблема.
            Не объяснение, а ввод в ситуацию.

[7-40 сек]  РАЗВИТИЕ
            Тезис + пример. Тезис + пример. Иногда тезис + 3 примера подряд.
            Каждые 5-7 секунд — смена плана/кадра/темпа.
            Один представитель ЦА, одна боль, одна мысль.

[40-50 сек] РАЗВЯЗКА / ПЕРЕВОРОТ
            Ответ на вопрос из хука, неожиданный поворот, итог.
            НЕ мораль, НЕ «вывод», НЕ «надо просто полюбить себя».

[50-60 сек] КОНЦОВКА
            Смешной момент / трогательный кадр / вопрос для комментов.
            Можно молчаливо: пауза, взгляд, шутка одним кадром.
```

**Длительность**: 30-60 секунд оптимально. Можно дольше, если контент держит — Уля упоминает 5-минутные ролики, которые залетают. Но это исключение.

## Шаблоны под каждый тип

### Охватный — «контраст»

```
[Хук]       Контраст в первой фразе или кадре (Ф4 из HOOKS.md)
[Контекст]  Кто это / в какой ситуации
[Развитие]  Развёрнутый контраст 2-3 пары
[Развязка]  Что это значит / куда это ведёт
[Концовка]  Шутка или вопрос на голосование
```

### Охватный — «личная история»

```
[Хук]       Категоричное утверждение о себе (Ф1) + цифра (Ф3)
[Контекст]  Что произошло
[Развитие]  Как развивалось / какие были этапы
[Развязка]  Что изменилось / что я поняла
[Концовка]  Что это даёт зрителю — намёк, не лекция
```

### Прогрев к личности — «трансформация»

```
[Хук]       Цифра/факт о вас «до»
[Контекст]  Как вы тогда жили / думали
[Развитие]  Что случилось, что заставило изменить
[Развязка]  Что вы делаете сейчас + конкретный результат
[Концовка]  Что вы поняли — и почему это нужно зрителю
```

### Продающий — «боль → инструмент → результат»

```
[Хук]       Конкретная боль ЦА (вопрос или утверждение)
[Контекст]  Кто чаще всего с этим сталкивается
[Развитие]  Покажи ошибку → покажи правильное решение
[Развязка]  Конкретный результат у конкретного клиента (кейс)
[Концовка]  Soft CTA: «если узнаёшь себя — напиши» / ссылка
```

### Продающий — «лайфхак + продукт»

```
[Хук]       Обещание результата (Ф9)
[Контекст]  В чём проблема, которая мешает большинству
[Развитие]  Мини-лайфхак (1 реальный приём, не вода)
[Развязка]  «Если это сработало — у меня в продукте Х таких приёмов»
[Концовка]  Прямой CTA
```

### Адаптация — «реакция на вирусное»

```
[Хук]       Кадр из чужого вирусного + ваша озвучка с категорией
[Контекст]  Почему это интересно (ваша интерпретация)
[Развитие]  Перенос на вашу тему (мост между чужим и вашим)
[Развязка]  Вывод по вашей экспертизе
[Концовка]  Вопрос или CTA
```

### Разбор инфоповода

```
[Хук]       Цитата/факт инфоповода + категоричная реакция
[Контекст]  Что произошло, в двух словах
[Развитие]  Что это значит на самом деле (ваш экспертный угол)
[Развязка]  Что зрителю с этим делать
[Концовка]  Эмоциональная точка
```

## Формат вывода

### Блок 1 — Три крючка

```
КРЮЧОК А [Ф1 + Ф3, уровень А]
[текст крючка одной фразой]
Почему: [1-2 строки — что цепляет]

КРЮЧОК Б [Ф4, уровень Б]
[текст]
Почему: [1-2 строки]

КРЮЧОК В [Ф8, уровень В]
[текст]
Почему: [1-2 строки]
```

### Блок 2 — Полный сценарий

Выбираешь один крючок (или Уля выбирает) и пишешь полный сценарий.

Правила записи:
- **Каждое предложение с новой строки**
- **Без эмодзи**, без заголовков-секций внутри сценария, без метаданных
- **«ё» → «е»** (еще, все, зеленый, черный)
- **Дефис `-` → минус `−`**
- В квадратных скобках — только пометки кадра: `[крупный план, лицо]`, `[пауза 1 сек]`, `[текст на экране: "30 000"]`, `[вставка: бабушка обнимает]`
- Реплики разных героев — с именем (если их двое): `Лена: ...` / `Я: ...`
- **Финал — переворот / шутка / вопрос**. Не мораль.

Пример мини-сценария:

```
Самая бесячая фраза в мире − наша свадьба окупилась.

[крупный план, лицо]

Сейчас объясню.

У моей бабушки 15 000 рублей пенсии.

[вставка: пожилая женщина считает деньги]

Может, 20 максимум.

У меня замуж выходила сестра.

Бабушка подарила, ну, 30 000 рублей.

[текст на экране: "30 000 ₽"]

Эти 30 000 при пенсии в 15 000.

Скорее всего, она копила несколько лет.

Во всем себе отказывала.

Чтобы окупить фоту.

[пауза]

Фоту.

[крупный план, недоумение в лице]

Что еще при нынешних ценах на свадьбу может стоить 30 000?

[текст на экране: "Спасибо, чехольчики"]
```

### Блок 3 — Визуальная подача (если нужно)

После сценария — короткий комментарий (3-5 строк): что снять, какие вставки нужны, чем смонтировать. Если ролик планируется как анимация — указать, что подойдёт `/storyboard` для раскадровки.

## Что сохранять

**Для клиента**: `~/Documents/Work/Clients/<имя>/scripts/YYYY-MM-DD-<slug>.md`
**Для Ули (свой блог / Reels-клуб)**: `~/Documents/Work/Reels-Club/scripts/YYYY-MM-DD-<slug>.md`

В файл: оба блока (крючки + сценарий) + дата + тема + цель (охват/прогрев/продажа).

Если в папке клиента есть `INDEX.md` — допиши строку: дата, тема, формат, крючок (короткий), кейс, эмоция.
