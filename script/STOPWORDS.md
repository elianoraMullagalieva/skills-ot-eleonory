# STOPWORDS — что вырезать, чего не делать, какие темы не брать

Это последний фильтр перед выдачей сценария. Прогоняй каждое предложение по списку.

---

## Стоп-слова: вырезать или заменить

### Вводные слова (под парные запятые)

Они вводятся в предложение через запятые и не несут смысла. Убираются без потерь.

- по-моему / по моему мнению
- мне кажется
- как известно / известно, что
- кстати
- между прочим
- иными словами
- в общем-то
- так скажем
- нужно сказать / надо сказать
- собственно
- разумеется
- наверное / возможно (в большинстве случаев)

**Почему вырезать**: они убивают категоричность. «По-моему, выходить замуж до 20 лет странно» = слабо. «Выходить замуж до 20 лет странно» = сильно.

### Модальные глаголы (часто лишние)

- можно
- нужно
- должен / должна / должны
- надо
- следует

**Правило**: если без них смысл сохраняется — выкидывай. «Можно использовать клетчатку» → «Используй клетчатку». «Нужно заниматься спортом» → «Занимайся спортом».

Не для всех случаев, но проверять каждое такое слово на необходимость.

### Неопределённые местоимения

- где-то
- как-то
- что-то
- какой-то / какая-то / какое-то
- кое-как
- каким-то образом

**Замена**: конкретика. «Где-то 20 человек» → «23 человека». «Как-то странно» → конкретное описание.

### Оценки-усилители (мусор)

- очень
- довольно
- весьма
- крайне
- прямо
- совершенно
- абсолютно
- просто (в роли усилителя, не как наречие)
- как раз
- в целом
- в принципе
- по большей части

**Почему вырезать**: усиление обычно ослабляет. «Очень классный ролик» слабее, чем «классный ролик». «Это совершенно гениально» слабее, чем «это гениально».

### Штампы

- без сомнения
- известный факт
- популярное мнение
- существует мнение
- стоит отметить
- таким образом
- подводя итог

**Особо запретные у Ули** (из её правил):
- данный (вместо «этот»)
- является (вместо живого глагола)
- осуществлять
- в рамках
- дорогие друзья
- хочу поделиться
- проработайте
- паттерны (как термин в Reels)
- в современном мире
- стоит отметить
- таким образом

### Слова-паразиты в письменной речи

В устной речи (если ролик с озвучкой) допустимы «вот», «ну», «блин», «короче» — они дают живость. Но в **записанном сценарии** при редактуре их нужно вычистить, оставив только там, где они работают как ритмический акцент.

## Запретные конструкции

### 1. Приветствие в начале
❌ «Привет, я Уля, сегодня расскажу...»
❌ «Здравствуйте, друзья!»
❌ «Всем привет, кто меня смотрит»

### 2. Объявление темы
❌ «Сегодня будем говорить о...»
❌ «В этом ролике расскажу про...»
❌ «Сейчас покажу три способа...»

### 3. Мораль в конце
❌ «Так что любите себя»
❌ «Поэтому всегда платите налоги»
❌ «Главное — верьте в себя»

### 4. CTA внутри сценки
❌ Внутри диалога двух героев один говорит «Подписывайся на канал!»
❌ В сценарии с эмоциональной развязкой — внезапно «А ещё у меня курс»

CTA — отдельно, после сценки, в финальном кадре или в описании.

### 5. Тезис без примера

❌ «Надо заниматься спортом, это полезно».
✅ «Нахида в 90 лет ежедневно бодибилдинг. Мамика в 92 года — инструктор по фитнесу».

### 6. Несколько мыслей в одном ролике

❌ Один ролик про доверие в команде, мотивацию сотрудников, конфликты руководителей и поиск себя.
✅ Один ролик про одну конкретную ошибку конкретного руководителя.

### 7. Узкая терминология в охватном

❌ «Корсетные мышцы пресса при работе с гипертонусом диафрагмы...»
✅ «Если у тебя после работы болит спина — вот что с тобой».

## Стоп-темы (риск бана или провала)

### Жёсткие бан-риски от Instagram

- **Сцены насилия** — кровь, побои, оружие в применении
- **Депрессия в негативном ключе** — суицид, самоповреждение, «всё плохо, не вижу выхода»
- **Волшебные таблетки** — обещания мгновенного результата без оснований («заработай миллион за неделю»)
- **РПП в опасном свете** — детальные истории похудения, до/после с экстремальными результатами
- **Политика и острые соцтемы** — война, политики поимённо, религиозные конфликты
- **Откровенный обман / мошенничество** — алгоритм ловит

### Темы, где надо быть осторожным

- **Деньги в больших цифрах без контекста** — может прочитаться как обман
- **Истории про несчастья (потери, болезни)** — лучше через осмысление, не через драму ради драмы
- **Конкретные люди (звёзды, политики)** — оскорбление = жалоба = бан
- **Шок-контент** (грязь, мерзости, тела) — может пройти, может прилететь страйк

### Темы, которые «не залетят» (узкая аудитория)

- Жизненный опыт, который есть только у 1% людей (был во Вьетнаме в 2018, видел редкий цветок)
- Узкие профессии без расширения на общую тему
- Региональные темы без общероссийского/мирового моста
- Узкоспецифические термины и явления без объяснения

## Голос Ули — то, что должно сохраняться

В её сценариях для **своего блога** должен звучать её голос. Маркеры:

### Любимые обороты

- «Завязла в операционке»
- «Крутить в голове»
- «Надоело»
- «Решила — сделала»
- «На самом деле»
- «Мне кажется» (как мягкое начало мнения)
- «Вот это вот...»
- «Глобально...»
- «То есть...»
- «Сейчас объясню»
- «Есть ощущение, что...»
- «Вообще» (расширение мысли)

### Манера

- Прямая, образная
- С характером
- Без «дорогих друзей»
- Без «хочу поделиться»
- Без коучингового мусора («полюби себя», «прими изобилие»)
- Решено — делаем. Без рефлексии в три абзаца.

### Возражает себе и зрителю

Уля любит «я понимаю, что..., но...». Это даёт живой контр-аргумент в монологе.

## Финальный чек-лист перед выдачей

Прогони сценарий по этому списку. Если есть нарушение — исправь.

### Содержание
- [ ] Крючок цепляет в первые 3 секунды (см. `HOOKS.md`)
- [ ] Одна мысль, один представитель ЦА
- [ ] Каждый тезис подкреплён примером
- [ ] Заголовок про **результат**, не **инструмент**
- [ ] Зритель видит себя в ролике, не вас
- [ ] Темы не из «бан-листа»
- [ ] Если это для клиента — проверь его `INDEX.md`, чтобы крючок не повторял предыдущие

### Голос
- [ ] Категоричность сохранена (без «может быть», «по-моему»)
- [ ] Вводные слова вычищены
- [ ] Оценки-усилители вычищены
- [ ] Модальные глаголы проверены (часть выкинута)
- [ ] Запретные слова Ули отсутствуют (данный, является, дорогие друзья и т.д.)
- [ ] Голос соответствует адресату: Уля / клиент / общий

### Форма
- [ ] Каждое предложение с новой строки
- [ ] «ё» → «е»
- [ ] Дефис `-` → минус `−`
- [ ] Без эмодзи внутри сценария
- [ ] Без заголовков-секций
- [ ] Финал — переворот / шутка / вопрос (не мораль)
- [ ] CTA отдельно от сценки (если есть)

### Структура
- [ ] Длительность 30-60 сек (или обоснованно дольше)
- [ ] Смена плана/кадра каждые 5-7 сек
- [ ] Развязка не сливает интригу в середине
- [ ] Концовка вызывает реакцию (комментарий / репост / сохранение)
