## JavaScript: кнопка отправки заблокирована пока все 3 не отмечены

```js
const cs = form.querySelectorAll('input[name^="c"]');
function updateBtn() {
  const allChecked = Array.from(cs).every(c => c.checked);
  submitBtn.disabled = !allChecked;
}
cs.forEach(c => c.addEventListener('change', updateBtn));
```

## Юридическое обоснование

### Галочка 1 — Политика конфиденциальности
Покрывается **152-ФЗ** «О персональных данных». Стандартное согласие на обработку данных без явного указания целей маркетинга.

### Галочка 2 — Согласие на рассылки
Покрывается **38-ФЗ** «О рекламе», статья 18. **Без этой галочки нельзя присылать маркетинговые рассылки** (приглашения на курсы, спецпредложения, продающие письма).

Если кто-то заполнил анкету без этой галочки — ему нельзя слать ничего кроме сервисных сообщений (по той услуге, которой он попросил).

### Галочка 3 — Согласие на обработку ПДн
Дополнительное подтверждение по 152-ФЗ, что человек прочитал отдельный документ «Политика обработки персональных данных».

### Почему именно 3 галочки

Юрист Эли требует именно такую структуру, потому что:
- Каждая галочка соответствует **отдельному правовому документу**
- Если в суде встанет вопрос «было ли согласие на маркетинг» — есть отдельная галочка, не упакованная в общее «согласие со всем»
- Это снижает риск штрафов ФАС при жалобах

### Почему оферта — отдельно в подвале

Оферта — это **договорной документ**, который активируется при покупке. Для бесплатной анкеты предзаписи оферта не применяется. Но ссылку в подвале держим для полноты юридического информирования.
