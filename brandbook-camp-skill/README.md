# 🦋 Скилл «Брендбук Дизайн Кэмпа»

Отдельная фирменная система продукта Дизайн Кэмп. Используется для любого контента (постов, лендингов, презентаций, ассетов), связанного с этим продуктом.

## Файлы

- **`SKILL.md`** — метаданные, когда использовать, как сочетать с голосом Эли
- **`BRANDBOOK.md`** — вся фактическая информация (палитра, программа, оценка, слоганы, инструменты)

## Как использовать

### Эли:
Скажи «сделай пост/баннер/лендинг для Дизайн Кэмпа» — Claude автоматически подтянет этот скилл вместе со скиллом голоса.

### Claude:
1. Прочитай `SKILL.md` чтобы понять контекст
2. Прочитай `BRANDBOOK.md` чтобы загрузить фактуру
3. Если задача про текст от лица Эли — обязательно также подгрузи `eli-voice-skill/SKILL.md`
4. Используй точные формулировки со слайдов (программа 01–04, не «Идея/Концепт/WOW/Код»)

## Когда обновлять

После каждого важного изменения в Кэмпе:
- Изменились цены — обновить раздел «Тарифы» (если будет добавлен)
- Изменилась программа — обновить раздел «4 этапа»
- Добавились/убрались инструменты — обновить раздел «Инструменты»
- Появились новые слайды брендбука — обновить «Палитра» и «Типографика»

## Связь с другими скиллами

- `eli-voice-skill/` — голос Эли, **применяется поверх** этого скилла когда пост от её лица
- `forms-telegram-bot-skill/` (в папке Сайты) — для форм Кэмпа использует данные отсюда
- В будущем: `brandbook-academy-skill/` для Академии Дерзай в Дизайн, отдельный
