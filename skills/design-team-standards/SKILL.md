# 🎨 Design Team Standards — Продакшн-качество

Этот скилл загружается автоматически когда дизайнер просит Claude помочь с HTML/CSS/React кодом для сайтов, лендингов и дизайн-систем.

## Кто мы
Студия создаёт премиальные лендинги и дизайн-системы. Клиенты — бизнесы в сегменте выше среднего. Вайб: Soho House × Kinfolk × A24. Никакого инфоцыганства, кислотного AI-визуала, шаблонных решений.

## ПРАВИЛА — нарушать запрещено

### 1. Пропорции медиа (фото и видео)
- **НИКОГДА** не обрезать фото через `object-fit: cover` с фиксированной высотой
- **НИКОГДА** не ставить `max-height: Xpx` на фото и видео если они должны быть в оригинальных пропорциях
- **ВСЕГДА**: `width: 100%; height: auto;` — контент адаптируется под медиа, не наоборот
- Объект, здание, деталь должны помещаться целиком — без обрезки краёв кадра

### 2. Контрастность текста — обязательно
- На **тёмном фоне** (#0a0a0a, #151719, #17252D) — текст минимум `rgba(255,255,255,0.75)` или кремовый `#DEDBC8` / `#E8E5D0`
- На **светлом фоне** — текст тёмный `#151719` или `#262428`
- **ЗАПРЕЩЕНО**: серый текст `rgba(255,255,255,0.25-0.45)` на тёмных подложках — нечитаемо
- Второстепенный текст (подписи, мета) — минимум `rgba(255,255,255,0.65)` на тёмном
- Перед финализацией — мысленно проверить контраст каждого текстового блока

### 3. Фоновые цвета
- **ЗАПРЕЩЕНО**: чистый `#000000` — всегда тёплый/холодный вариант
- Для тёмной темы: `#0a0a0a`, `#0d0d0d`, `#111111`, `#151719`, `#17252D`
- Для светлой: `#F1F1F1`, `#F8F8F8`, `#ECECEC` — не чистый белый если фон

### 4. Цвета — только из Figma проекта
- Всегда брать точные цвета из Figma файлов, не придумывать
- Пример записи палитры проекта: Brand Primary `#7C8E46`, Brand Accent `#A8C060`, Background `#17252D`, Card `#1E2B32`
- Пример тёмной палитры: Cream `#DEDBC8`, Background `#0a0a0a`, Accent Green `#b8c97a`, Gold `#C8A96E`

### 5. Типографика
- Пример: системный стек / Manrope
- Пример: Almarai (Google, заголовки) + кириллический serif для курсивных акцентов + Inter (body)
- Letter-spacing для капсов: минимум `0.08em`, обычно `0.12-0.2em`
- Никаких `font-size: 10px` для основного читаемого контента

### 6. Анимации
- Framer Motion для React-проектов
- `ease: [0.16, 1, 0.3, 1]` — стандартный spring-ease студии
- Видео всегда: `autoplay muted loop playsinline`
- Fade-in при скролле через `useInView` с `once: true, margin: '-80px'`

### 7. Отступы и ритм
- Между секциями: `140px` (стандарт студии)
- Клонировать отступы из Figma, не придумывать
- `clamp()` для адаптивных размеров — обязательно

## Чеклист перед сдачей кода

Перед финализацией любого HTML/CSS/React компонента мысленно пройти:

- [ ] Все `<img>` и `<video>` имеют `height: auto` (нет `max-height` с `object-fit: cover`)
- [ ] Весь текст на тёмных фонах — минимум 0.75 opacity
- [ ] Нет `background: #000000` — только тёплые/холодные варианты
- [ ] Цвета совпадают с Figma проекта (не придуманы)
- [ ] Видео имеют `autoplay muted loop playsinline`
- [ ] Адаптив работает на мобильных (grid → 1 колонка)
- [ ] Отступы между секциями 140px (или из Figma)

## Стандарт качества

Каждая страница должна выглядеть как **indie-fashion campaign или creative-tech editorial**, а не типичный образовательный курс или шаблонный сайт. Просторные кинематографичные композиции, много воздуха, premium без пафоса.
