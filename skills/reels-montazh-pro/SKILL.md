# Монтаж Reels: нарезка дублей → цвет → графика-наложение → звук → сборка

`SKILL_DIR` ниже — папка этого скилла (обычно `~/.claude/skills/reels-montazh-pro`). Все скрипты — `python3 SKILL_DIR/scripts/<имя>.py --help`.

## 0. Приветствие при первом запуске

Если пользователь в этом разговоре впервые обращается к скиллу — или пишет «привет», «что ты умеешь», «как пользоваться», «начнём» — СНАЧАЛА коротко представься текстом из `ONBOARDING.md` (раздел между линиями): 9 пунктов возможностей и 3 стартовые команды. Тон дружелюбный и прямой, без лишних эмодзи, без воды. Один раз за разговор; если человек сразу прислал задачу — представься одной-двумя строками и делай задачу.

## 1. Перед работой

1. `python3 SKILL_DIR/scripts/check_env.py` — что стоит, чего нет. Нет чего-то → скажи автору одну команду установки (`pip install -r SKILL_DIR/requirements.txt && python3 -m playwright install chromium`, ffmpeg через brew/winget/apt) и не обходи.
2. Проект — своя папка рядом с видео автора. Тяжёлое (исходники, рендеры) не перемещать и не удалять.
3. Если сомневаешься, что всё работает: `python3 SKILL_DIR/scripts/selftest.py` — сквозной прогон на синтетическом ролике (~1 мин).
4. Видео автора смотри контакт-листом: `ffmpeg -i ролик.mp4 -vf "fps=1/2,scale=160:-1,tile=12x4" -frames:v 1 all.jpg` → Read.

## 2. Пайплайн А — нарезка дублей в чистые ролики

1. **Цвет.** iPhone пишет HDR (HLG / Dolby Vision). Если ролики пойдут в CapCut или телефон — сначала `python3 scripts/to_sdr.py IMG_1234.MOV` → `IMG_1234_SDR.mov` (см. пайплайн Б). Расшифровка и тайминги у SDR-файла те же.
2. **Расшифровка:** `python3 scripts/transcribe.py IMG_1234.MOV --prompt "Claude Code, CapCut, Figma"` → `IMG_1234.words.json` (слова со временем и вероятностью) и `IMG_1234.transcript.txt` (строки `слово@секунда`). Читай transcript целиком: где дубли, где «погнали / ещё раз / угу», где оговорки.
3. **Лучшие дубли:** есть сценарий (по фразе на строку) → `python3 scripts/pick_takes.py IMG_1234.MOV --script сценарий.txt --plan plan.json --reel Ролик1` — найдёт все дубли каждой фразы, оценит и запишет черновик плана. Сценария нет → `pick_takes.py IMG_1234.MOV` сгруппирует похожие фразы, а план напиши сам.
   Оценка дубля: разборчивость (средняя и минимальная вероятность слов whisper), шипение (доля энергии 6–12 кГц относительно медианы записи), паузы внутри, паразиты, повторы, совпадение текста со сценарием. ★ — лучший. Последний дубль часто лучший (автор повторяет, пока не получится), но решает балл и слух.
4. **План** (`plan.json`, формат — `examples/plan.example.json`): ролик = список кусков `[сек ПЕРВОГО слова, сек НАЧАЛА ПОСЛЕДНЕГО слова, текст]`. Несколько исходников — `"sources"` с `"offset": 1000` для второго (его секунды пишутся как 1000+). Ролики обычно: полный дубль A, полный B, «комбо» лучших фраз из A и B, короткая версия.
5. **Проверка плана без рендера:** `python3 scripts/cut.py plan.json` — таблица резов и предупреждения: пауза внутри куска (режется сама), паразит, повтор слова, «вторая цифра не похожа на начало слова», неразборчивое последнее слово. Покажи автору таблицу (сек → текст → длительность) и дождись «ок».
6. **Рендер:** `python3 scripts/cut.py plan.json --render` → `out/<ролик>.mp4`. Кодек сам: HDR-исходник → HEVC 10 бит HDR (мастер), SDR → H.264 8 бит (CapCut/телефон). Быстрый просмотр — `--preview` (1080p).
7. **Проверка расшифровкой (обязательно):** `python3 scripts/cut.py plan.json --verify` — каждый готовый ролик расшифровывается заново; по каждому куску: совпал ли текст, не упирается ли последнее слово в рез, не съедено ли окончание, не пролез ли паразит. Всё ✓ — только тогда показывай. Заодно появится `out/<ролик>.words.json` — слова готового ролика (для графики и `at_word` в монтаже).
8. **DaVinci:** `python3 scripts/fcpxml.py plan.json` → `Проект_для_DaVinci.fcpxml`: каждый ролик — таймлайн с теми же резами, под каждым куском весь исходник (край куска тянется). DaVinci: File → Import → Timeline → файл → OK. Экспорт: Deliver → MP4, H.265 (Apple), размер как у исходника.

### Правила резов (уроки, не нарушать)
- **Последнее слово фразы задаётся по НАЧАЛУ слова из транскрипта, а тишина ищется от его КОНЦА.** Если вторую цифру ставить по концу слова или искать тишину от начала — съедаются окончания («монтаж» → «монта»).
- **Паузы внутри «одного» дубля режь.** Автор делает паузу посреди фразы (подумать, вдох) — это тоже «тупняк». `cut.py` сам делит кусок на паузах длиннее `split_pauses` (0.5 с), но проверь таблицу: пауза для смысла (драматическая) — поставь `"split_pauses": 0` или раздели кусок вручную иначе.
- **На стыке соседних кусков убирай микроперекрытие:** если два куска идут подряд из одного места записи, второй начинается ровно там, где кончился первый (`cut.py` делает сам) — иначе слышен повтор слога.
- **Whisper часто ставит начало слова РАНЬШЕ звука** (в тишину) — отсюда «мёртвые» 0.2–0.6 с перед фразой. `cut.py` ищет реальный первый звук и захватывает тихие первые звуки («У-станавливаем»). Если начало всё равно съедено или лишнее — ручная точка в `"ovr": {"сек_первого_слова": сек_реза}`.
- **После рендера — расшифровать результат и проверить, что каждая фраза целая** (`--verify`). На слух тоже: первые и последние слоги каждого куска.
- Мягкие фейды звука 12–15 мс на каждом стыке уже стоят — щелчков нет. Видео режется по кадрам, звук — по сэмплам; длительности в `plans.js` — целые кадры (синхрон графики до кадра).
- Whisper плохо расслышал ключевое слово (имя, кодовое слово, термин) — НЕ угадывай, спроси автора; для повторной расшифровки дай `--prompt`.

## 3. Пайплайн Б — HDR → SDR (нормальный цвет без бликов)

- `python3 scripts/to_sdr.py IMG_1234.MOV [--capcut]`.
- **macOS: ТОЛЬКО движок Apple** — `sdr_apple.swift` (AVAssetExportSession + видеокомпозиция Rec.709, как «Фото» при экспорте). Разрешение, fps и звук сохраняются. 4K-ролик переводится примерно за реальное время.
- **Свой LUT / тонмаппинг НЕ делать.** Самодельный LUT HLG→709 автор назвала «ужасной цветокоррекцией» — пересвет кожи, грязные тени. Apple делает правильно.
- **Windows/Linux:** запасной ffmpeg (zscale + tonemap hable, иначе libplacebo, иначе только матрица) — скрипт предупредит; скажи автору, что цвет будет хуже, и предложи перевести на Mac или экспортировать с iPhone как «Наиболее совместимый».
- **Не растягивать видео выше исходного разрешения** — ни при переводе, ни в монтаже (мыло). Нужна 4K-графика — рендери её крупнее (`--scale 2`), а не растягивай.
- **Для CapCut — H.264 8 бит** (`cut.py --codec h264` по SDR-исходнику или `to_sdr.py --capcut`). 10-битный HEVC CapCut иногда показывает как «файл повреждён».

## 4. Пайплайн В — графика-наложение под таймкоды речи

Стиль и метафоры — как в соседнем скилле `reels-infografika` (его `SKILL.md`, библиотека метафор и `example/` — эталон уровня). Здесь — движок для нескольких роликов из одной записи и форматов CapCut-раскладки.

1. **Стиль:** сайт/бренд автора → шрифт, фон, ОДИН акцент (со скриншотов, не из CSS), 3–5 фирменных элементов (`reels-infografika/site_shots.py`). Напиши автору, что взял, дождись «ок».
2. **Папка графики:** скопируй `SKILL_DIR/engine/grafika.html` и `SKILL_DIR/engine/fonts/` в папку проекта. Рядом:
   - `plans.js` — `python3 scripts/cut.py plan.json --plans-js grafika/plans.js` (+ `СЛОВА_ПО_КУСКАМ.md` — по нему ставишь сцены);
   - `words.js` — `python3 scripts/transcribe.py IMG_1234.MOV --words-js grafika/words.js` (для `W('слово')`; не нужен — удали тег);
   - `scenes.js` (и `scenes_2.js`… — подключи тегами в `grafika.html`). Пример — `examples/scenes.js`.
3. **Формат:** `window.STAGE` в `plans.js` или `?format=` — `'5x3'` 1080×648 (рендер ×2 = 2160×1296), `'1080x756'`, `'sq'` 1080×1080, либо `[ширина, высота]`. Размеры текста движок ставит сам (3 размера: hero / mid / cap).
4. **Сцены в секундах ИСХОДНИКА, не ролика:** `S(a, b, 'D'|'L', html, (t,q,qa)=>{…})`. Одна библиотека на все ролики: `render(t)` переводит время ролика в время исходника по `plans.js` и показывает только сцены, попавшие в куски этого ролика. Сцена на фразу, которая есть в двух дублях, — пишется для каждого дубля (или циклом по `W('слово', n)`).
5. **Кадр = чистая функция от t.** `IN()` появление, `WT()` слова по точным секундам, `P()` прогресс с easing, `DRAW()` штрих, `typed()` печать, `R(i)` детерминированный рандом (`Math.random` нельзя). Реалтайм-анимацию с записью экрана НЕ использовать — плывёт синхрон.
6. **Просмотр:** открыть `grafika.html?reel=1` (пробел — пауза, ←/→ ±1 с, `&t=12.3` — стоп-кадр; внизу время ролика и исходника).
7. **Проба:** `python3 scripts/render_overlay.py --html grafika.html --reel 1 --start 0 --end 10 --out test.mp4` → контакт-лист → Read → правки.
8. **Весь ролик:** `python3 scripts/render_overlay.py --html grafika.html --reel 1 --scale 2 --out Наложение_ролик1.mp4 --audio out/Ролик1.mp4` (`*_so_zvukom.mp4` — проверить синхрон на слух).
9. **Мельтешение:** `python3 scripts/flicker_check.py Наложение_ролик1.mp4` — смены кадра чаще 0.9 с. Нашлось → объединить сцены / сдвинуть смену на следующее слово.

### Темп и вкус (жёстко)
- **Спокойно:** `SLOW≈1.35` (все движения медленнее, моменты старта не сдвигаются), смены сцен не чаще ~1.2 с, **одна акцентная деталь на кадр**, 3 размера текста, 2 жирности.
- Появление — на слове или на 0.1–0.2 с раньше, никогда позже. Ключевые слова короткие, всю речь в графику не переносить.
- Кадр живёт (лёгкое дыхание, бегущая точка), но не дёргается. Статичный кадр — брак, мельтешение — тоже брак.
- Место под лицо автора не перекрывать: наложение — только своя зона (сверху), раскладку согласуй.

### Вставка реальных записей экрана (туториал)
1. Кадры: `python3 scripts/clip_frames.py запись.mp4 frames/copy --from 1.2 --to 19.05 --width 1760` → `frames/copy/f_001.jpg…` (30 к/с; ширина ≈ 2× окна в сцене, не больше исходной записи).
2. В сцене: `<img class="fr">` в окне браузера/приложения; `setFrame(img,'frames/copy',frameNo(rec(t), 1.2))`; `place(img,W,H,зум,фx,фy)` — наезд на нужное место.
3. **Привязка записи к словам — кусочно-линейная:** `const rec=timeMap([[сек_исходника, сек_записи], …])` — «клик» в записи ставишь на слово «нажимаем», «вставка» — на «Ctrl V»; между опорами запись ускоряется/замедляется сама.
4. `render()` ждёт `decode()` каждого нового кадра (`window._pend`) — в видео нет пустых и недогруженных кадров. `preload(dir)` — первый кадр заранее.

### Звуки — только на действиях
- `window.SFX=(window.SFX||[]).concat([[сек_исходника,'click'], …])` в сценах; типы: `click, copy, paste, send, pop` (есть ещё `whoosh, ding, type` — по умолчанию выключены).
- `python3 scripts/mix_sfx.py --html grafika.html --reel 1 --voice out/Ролик1.mp4 --mux Наложение_ролик1.mp4` → `sfx_r1.wav`, голос+эффекты для прослушки и `Наложение_ролик1_sfx.mp4` (наложение с дорожкой эффектов — в CapCut громкость наложения = громкость эффектов).
- Не чаще раза в 0.8 с, тихо, мягко. Не на каждую сцену и не на появление текста — только на действие в кадре (клик, копирование, вставка, отправка, «выпрыгнуло»).
- Звуки синтезированы (`sfx/gen_sfx.py`, без чужих сэмплов). Поменять характер — правь генератор и перегенерируй.

## 5. Пайплайн Г — финальная сборка «как в CapCut»

`python3 scripts/montage.py montage.json` (формат — `examples/montage.example.json`): холст (обычно 2160×3840, 60 к/с), слои по порядку (последний сверху) — видео автора со сдвигом/кропом, наложение сверху, вставки; громкость каждого слоя; вставка на времени `"at"` или на слове `"at_word": "сайтов"` (по `words` готового ролика). Выход — H.264 8 бит Rec.709 (CapCut/Instagram).
- Кадр для проверки раскладки: `--frame 12.5` → png → Read.
- Растяжение слоя выше его размера скрипт помечает ⚠ — рендери источник крупнее.

### Снять раскладку из проекта CapCut автора
Автор уже собрала эталон в CapCut → `python3 scripts/capcut_layout.py "<проект>/draft_info.json" --out montage.json` (macOS: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/<имя>/`, Windows: `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft\<имя>\`). Что внутри `draft_info.json` и как пересчитывается (если файл зашифрован новой версией CapCut — считай вручную по тем же формулам со скриншота панели «Трансформация»):
- `canvas_config.width/height` — холст проекта (1080×1920); итог 4K = ×2.
- `materials.videos[].crop` — углы кропа в долях исходника (`upper_left_x … lower_right_y`) → пиксели кропа.
- Обрезанный кусок вписывается в холст: `base = min(Cw/cw, Ch/ch)`, размер = `crop × base × clip.scale`.
- `clip.transform.x/y` — сдвиг **центра кропа** в долях **половины холста**, y вверх положительный: `cx = Cw/2 + x·Cw/2`, `cy = Ch/2 − y·Ch/2`. **Кроп центрируется**: в точку ставится центр обрезанного куска, а не исходника.
- `target_timerange.start` — когда слой появляется (мкс), `source_timerange.start` — откуда берётся; `segment.volume` — громкость; `render_index` — порядок слоёв.
- Пример (проверено): видео 2160×3840, `transform.y = −0.6164` → сдвиг вниз на 1183.5 px в 4K; наложение 2160×2160 с кропом по y 0.0143–0.9060 → строки 31–1957, `y = 0.4987` → вплотную к верху; вставка 3418×1978 с кропом и `scale 0.963` → 2080×1204 в (40, 674).
- **Сверка с экспортом автора:** `python3 scripts/montage.py montage.json --compare экспорт_из_CapCut.mp4 --times 3,20,40` — разница кадров (средняя < 2% и худшая клетка < 6% — совпало; сдвиг на 26 px или вставка не на месте дают ⚠). Совпало → дальше собирай новые ролики тем же конфигом, меняя файлы и `at_word`.

## 6. Что показывать автору и когда
1. После расшифровки — что нашёл: дубли, паузы, оговорки, места под вставки; план роликов (таблица). Ждать «ок».
2. После нарезки — ролики + итог `--verify` + где лежит `.fcpxml` (если захочет подвинуть резы).
3. Графика — сначала проба 10 с и контакт-лист, потом весь ролик.
4. Финал — путь к файлу, длительность, что проверено (расшифровка, мельтешение, сверка с CapCut).
Пиши коротко и по-человечески: «готово, 3 ролика по 40–55 с, все фразы целые; в ролике 2 убрала паузу после „вначале“».

## 7. Скрипты
| скрипт | что делает |
|---|---|
| `check_env.py` | проверка окружения и команды установки |
| `transcribe.py` | whisper по словам (mlx-whisper / faster-whisper / whisper), `--words-js` для графики |
| `pick_takes.py` | оценка дублей (разборчивость, ВЧ-шипение, паузы, паразиты) → черновик плана |
| `cut.py` | резы по словам + доводка по тишине, автонарезка пауз, стыки, рендер, `--plans-js`, `--verify` |
| `fcpxml.py` | проект для DaVinci / Final Cut с теми же резами |
| `to_sdr.py` + `sdr_apple.swift` | HDR → SDR движком Apple (macOS) или ffmpeg (иначе), `--capcut` |
| `render_overlay.py` | покадровый рендер HTML-графики (`--reel`, `--scale 2`, `--query`) |
| `clip_frames.py` | запись экрана → кадры jpg для вставки |
| `mix_sfx.py` | звуки на действиях из `window.SFX`, голос+эффекты, `--mux` в наложение |
| `montage.py` | финальная сборка по JSON (слои, кроп, сдвиг, громкость, вставка на слове), `--frame`, `--compare` |
| `capcut_layout.py` | `draft_info.json` CapCut → `montage.json` |
