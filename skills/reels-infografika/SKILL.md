# Инфографика для Reels по таймингу речи (любая ниша)

Эталон качества — `example/результат/grafika.html` (ролик «ИИ-продавец», 32 сцены на 73 секунды, бренд НейроПрактикума) и его контакт-листы `example/результат/контакт-лист.jpg` (кадр каждые 1.5 с) и `контакт-лист_каждая_секунда.jpg`. Видео эталона в публичный репозиторий не кладём (тяжёлое): `grafika.html` можно отрендерить самому через `render.py`.
В `example/` лежит то, из чего эталон собран:
- `исходник/` — расшифровка речи по словам (сам ролик автора не прикладывается);
- `РАЗБОР.md` — что взято с сайта и раскадровка «секунда → речь → визуал»;
- `результат/` — готовый монтаж: `grafika.html` и два контакт-листа. Сайт-источник стиля в публичную версию не входит: что с него взято, расписано в `РАЗБОР.md`.

**Перед работой прочитай `example/РАЗБОР.md` и `example/результат/grafika.html` ЦЕЛИКОМ и посмотри через Read `example/результат/контакт-лист.jpg`.** Так видно, какого уровня ждут: как по конкретной речи и конкретному сайту получилась конкретная графика. Копировать надо УРОВЕНЬ, приёмы и движок. Бренд и смыслы берутся у текущего автора.

## Что берётся у автора, а что остаётся неизменным
| Меняется под автора | Не меняется никогда |
|---|---|
| палитра, акцент, шрифт (с его сайта) | движок `render(t)` + покадровый `render.py` |
| угловые подписи (бренд, тема ролика) | тайминг по СЛОВАМ |
| фирменные элементы сайта (строки, карточки, кнопки, фактуры) | сцена ≤ 2 сек, 1 метафора на фразу |
| метафоры под его нишу | 3 размера текста, 2 жирности, 1 акцент на кадр |
| | самопроверка контакт-листом до показа |

## Почему это работает (не выкидывать ни один пункт)
1. **Время — чистая функция.** `render(t)` рисует кадр для любой секунды, а `render.py` снимает кадры по одному. Благодаря этому синхрон совпадает до кадра, кадры не теряются и можно перемотать на любую секунду. Реал-тайм запись (anime.js + запись экрана) НЕ использовать: она плывёт.
2. **Тайминг по СЛОВАМ, а не по фразам.** Whisper выдаёт время каждого слова, и каждый элемент появляется на своём слове (`IN(el,t,23.8)` = слово «нельзя» на 23.8 с).
3. **Сначала изучи сайт, потом рисуй.** Графика строится из реальных элементов сайта: нумерованные строки «01 … +», карточки, кнопки ↗, зерно, крестики. Поэтому она выглядит фирменной, а не «AI-шаблоном».
4. **Каждой фразе своя визуальная метафора.** Текст только подписывает её. Проверка: если убрать текст, всё равно понятно, о чём сцена.
5. **Одна сцена длится не больше 2 секунд.** Длинную фразу режь на 2–3 микро-сцены.
6. **Жёсткие ограничения:** 3 размера текста, 2 жирности, 1 акцентный цвет.
7. **Проверь сам, прежде чем показывать.** Контакт-лист всего ролика смотри через Read, ищи наложения, пустые кадры и вылезающий текст.

## Пайплайн (строго по порядку)
1. **Транскрипт:** `python3 <папка скилла>/transcribe.py "<ролик>.mp4"` выводит строки вида `слово@секунда`.
2. **Посмотри ролик:** `ffmpeg -i ролик.mp4 -vf "fps=1/2,scale=160:-1,tile=13x3" -frames:v 1 all.jpg` и прочитай картинку через Read. Отметь, где в ролике УЖЕ есть скрины и вставки, и скажи автору.
3. **Изучи бренд:** `python3 <папка скилла>/site_shots.py <url|папка> ./site`. Скрипт выдаст шрифты, цвета, `:root` и контакт-лист, который надо посмотреть через Read. Выпиши:
   - фон, основной цвет, ОДИН акцент;
   - шрифт. Если это не Manrope, скачай .ttf с Google Fonts в `fonts/` и поменяй `@font-face`. Нужны две жирности: жирная (700–800) и светлая (300);
   - 3–5 фирменных элементов сайта (форма карточек, кнопок, списков, фактура, декор).
   Сайта нет → спроси у автора 2–3 референса или цвета. Если ответа нет, бери стиль эталона.
4. **Сначала напиши автору, что понял:** формат, шрифт, стиль и какие элементы сайта переиспользуешь. Дождись «ок» или правок, только потом код.
5. **Раскадровка:** таблица «секунды → фраза → визуальная метафора». Ключевые слова только короткие, всю речь в графику не переносить.
6. **Код:** скопируй `template.html` в папку проекта вместе с папкой `fonts/`. Сцены пиши через `S(a,b,html,draw)`. Выстави `window.DURATION` равным длине ролика (`ffprobe`). В `:root` подставь бренд. Акцент везде задавай через `var(--red)` / `ACC`, НЕ хардкодом (в эталоне `#e73b23` стоит хардкодом, при копировании сцен заменяй).
7. **Первые 10 секунд:** `python3 <папка скилла>/render.py --html grafika.html --out test.mp4 --end 10.3`, затем контакт-лист, затем проверь сам.
8. **Весь ролик:** `python3 <папка скилла>/render.py --html grafika.html --out grafika.mp4 --audio "<ролик>.mp4"`. Появится ещё `grafika_so_zvukom.mp4` для проверки синхрона.
9. **Проверка:** `<папка скилла>/contact.sh grafika.mp4`, затем Read. Исправь найденное и только потом показывай.

## Формат и стиль
- Холст **1080×1040**. Сцены смещены на +60px вниз, центр масс держи около 450–520px.
- Декор всегда: вверху слева бренд (mono), вверху справа тема ролика, внизу крестики `+` и счётчик `[ 07 / 32 ]`. Если на сайте автора декор другой, бери его.
- Фон и фактура с сайта (в эталоне это `#070707`, SVG-зерно, смещается 12 раз в секунду, и мягкий glow). Сайт светлый → тёмные значения зеркалятся в светлые, а контраст и правило одного акцента остаются.
- **Шрифт** с сайта автора (по умолчанию Manrope): жирная для hero и выделенного слова, 300 для всего остального. Hero с плотным кернингом (-0.065em). Моно-шрифт только для технических подписей.
- **Три размера текста:** hero 150 (можно ужать до 110–150), mid 64, cap 40. Других нет.
- **Цвет:** основной, серый вторичный, тонкие линии и **акцент бренда ОДНОЙ деталью на кадр**. Заголовок из нескольких слов в 2 цвета не красить. Эмодзи нельзя, только SVG-иконки линией.
- Карточки: чуть светлее фона, граница 1px, скругление как на сайте. Скелетон-строки (`.sk`) вместо выдуманного текста.

## Как придумать метафору под ЛЮБУЮ нишу
Для каждой ключевой фразы спроси себя: **какое ДЕЙСТВИЕ с предметом показывает смысл?** Подпись к слову — это не метафора.
1. Найди в фразе глагол или результат: «закрыл сделку», «похудела на 8 кг», «вырос в 3 раза», «запрещено».
2. Подбери предмет из мира ниши:
   - фитнес: весы, пульс, кольцо активности, гантель;
   - психология: узел → распутанная нить, батарейка энергии;
   - недвижимость: план квартиры рисуется, ключ, ипотечная шкала;
   - бьюти: флакон, до/после шторкой, палитра;
   - финансы (осторожно с Instagram-ограничениями по деньгам): график, копилка, шкала целей;
   - эксперт/обучение: чек-лист, прогресс, сертификат, этапы-строки.
3. Дай предмету движение из движка: рисуется stroke, набегает счётчик, падает, всасывается в ядро, меняется местами, выпрыгивает с back-easing.
4. Числа из речи → счётчик + визуальная доля (дуга, сетка точек, столбики). **Цифры, которых нет в речи, НЕ выдумывать.**
5. Сравнения / «до и после» → две карточки или два столбика, выигрышная сторона в акценте.
6. Абстракции (опыт, доверие, стиль) → поток частиц от одного к другому + прогресс-бар.

## Библиотека метафор (фраза → визуал из эталона)
Готовые решения из эталона. Они универсальны, адаптируй объекты под нишу:

| Смысл во фразе | Визуал |
|---|---|
| «шок / вау» | hero со slam-масштабом 1.8→1 + радиальные штрихи-вспышка |
| «навайбкодила / сделала ИИ» | терминал Claude Code печатает строки → символы кода слетаются в аватар-робота с кольцом |
| «к утру / ночью» | луна заходит, солнце встаёт + часы 23:00→07:00 |
| «сделка / продажа» | карточка-уведомление падает сверху (back-easing) + красный квадрат с галочкой, которая рисуется |
| «без меня» | иконка человека + красная черта |
| «как это?» | «?» рисуется красным штрихом |
| «загрузила мозг» | мозг рисуется stroke + прогресс-бар 0→100% + частицы летят вверх |
| «два профиля / варианта» | две карточки разъезжаются от центра, связь — кривые с бегущими точками |
| большое число | счётчик tabular-nums + фон из чат-пузырей, выпрыгивающих со stagger |
| «люди / аудитория» | сетка иконок-людей, волна появления от центра, 1 красная |
| перечисление 3+ пунктов | строки как на сайте: `01 · текст · +`, активная белая 800, «+» поворачивается и краснеет, линии рисуются scaleX |
| «нельзя / запрет» | объект + красный знак запрета рисуется, объект трясётся, пузырь падает |
| «100 человек» | сетка 10×10 точек загорается синхронно со счётчиком |
| «написала лично» | окно чата: печать в поле → отправка → пузырь |
| «N минут» | циферблат, красная дуга = доля часа, стрелка |
| «отдыхать» | чашка + пар (штрихи рисуются и плывут) |
| «интеграции / сервисы» | узлы-сервисы вокруг ядра «ИИ», пакеты бегут по линиям; «не только» → сеть гаснет, красная черта |
| «передала опыт» | я → поток частиц → агент + прогресс-бар |
| «хорошее и плохое» | две стопки карточек ✓ / ✕ влетают с боков → всасываются в ядро с рябью |
| «уволить / убрать» | ряд аватаров падает вниз с вращением (гравитация f²) |
| «лучше всех» | столбики: один красный выстреливает с overshoot |
| «годы / путь» | таймлайн рисуется, точка бежит, в конце белая карточка-результат |
| «фразочки / шутки» | цитатные пузыри «» летят в ядро; «ха-ха» пузыри выпрыгивают с покачиванием |
| «разговоры / голос» | волна из 44 баров |
| «не отличить» | «напёрстки»: карточки «я / ИИ» → метки становятся «?» → карточки меняются местами по дуге 3 раза |
| «проверить» | лупа рисуется и описывает круги |
| «пишите слово» | поле ввода как на сайте, слово печатается, курсор жмёт красную кнопку ↗ |
| «скину ссылку» | бумажный самолётик по пунктирной кривой → карточка агента «онлайн» |
| финальный вопрос | две кнопки сайта (белая / контурная) + курсор выбирает, hover = красный outline |

## API движка (в template.html)
- `S(a,b,html,draw)`: сцена видна с `a` до `b`, уход 0.15 с. `draw(t,q,qa)`, где `q` — querySelector внутри сцены.
- `IN(el,t,старт,{dx,dy,s0,d,e,out})`: появление; `out:сек` — уход внутри сцены (фаза 1 → фаза 2 на одном месте).
- `P(t,старт,длит,'expo'|'back'|'out'|'io')`: прогресс 0..1. `DRAW(path,p)`: рисование штрихом (у path обязательно `pathLength="1"`).
- `typed(str,t,старт,сек_на_символ)`: печать. `T(el,{x,y,s,r,o})`: трансформ. `R(i)`: детерминированный рандом (Math.random НЕЛЬЗЯ, рендер должен повторяться).
- `PERSON()`, `ROBOT()`, `BRAIN` — готовые SVG. Для движения по кривой: `path.getPointAtLength()`.
- Превью в браузере: пробел — пауза, ←/→ — ±1 с, `?t=12.3` — стоп-кадр.

## Темп
- Появление 0.35–0.45 с, печать 0.02–0.05 с на символ, back-easing для «выпрыгивания».
- Кадр всегда живёт: микро-дыхание (sin, амплитуда ≤ 4–6px / ≤ 1.04), бегущие частицы, мигание глаз робота. Статичный кадр — брак.
- Появление ставь на слово или на 0.1–0.2 с РАНЬШЕ него, но никогда позже.

## Грабли, которые уже ловили
- **Акцент бери со СКРИНШОТОВ, а не из CSS.** На сайте эталона в CSS стоит `--lime:#c6f33a`, но визуально доминирует красный из фото работ. Правильным акцентом оказался красный `#e73b23`.
- Длинный уход сцены (0.28 с) даёт наложение текста на текст на стыке. Уход не длиннее 0.15 с.
- Фазы одной сцены (mid «никому из них» → hero «нельзя») кладутся абсолютно в одно место. Первую уводить через `out:`.
- Если whisper плохо расслышал ключевое слово (кодовое слово, имя), НЕ угадывай молча, а спроси автора.
- Композиция по умолчанию липнет к верху. Держи центр масс около 450–520px (с учётом смещения +60).
- `sed` с `${…}` в шаблонных строках не матчится, править через python `str.replace` с assert.

## Окружение
Нужны macOS/Linux, `ffmpeg`, `python3` + `playwright` (chromium) и `mlx-whisper` (Mac M-серии) или `faster-whisper`. Ставится так: `pip install playwright numpy && python3 -m playwright install chromium`, плюс `pip install mlx-whisper` (Mac M1–M4) или `pip install faster-whisper` (Windows/Linux/Intel Mac). `<папка скилла>` — обычно `~/.claude/skills/reels-infografika`. Если чего-то нет, сначала скажи автору, что поставить, и не пытайся обходить.
