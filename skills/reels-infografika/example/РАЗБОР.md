# Разбор эталона «ИИ-продавец»: как из речи получилась графика

Что лежит в этой папке:
- `исходник/расшифровка.txt` — речь по словам (сам исходный ролик не прикладывается);
- `результат/grafika.html` — готовый монтаж (код; видео получается через `render.py`);
- `результат/контакт-лист.jpg` — кадр каждые 1.5 сек, `контакт-лист_каждая_секунда.jpg` — кадр каждую секунду.

Сайт автора и его скриншоты в публичную версию не входят (это личный сайт). Таблица ниже показывает, какие элементы с него взяты, — по ней видно, как переносить стиль ЛЮБОГО сайта.

## Что взято с сайта
| На сайте | В графике |
|---|---|
| чёрный фон `#070707` + SVG-зерно (`styles.css`, `body::before`) | фон и зерно, смещается 12 раз в секунду |
| Manrope 800, letter-spacing -0.065em (`.hero h1`) | hero-текст |
| красные фото работ + `--footer-accent:#e73b23` | единственный акцент |
| крестики `+` по углам hero (`.hero::before`) | крестики внизу кадра |
| мелкие uppercase-подписи (`.eyebrow`) | mono-подписи в углах |
| строки программы «01 · Настройка… · +» | сцена с перечислением (мастер-классы / вебинары / обучалки) |
| карточки «Для кого» | карточки «личный / рабочий», «я / ИИ» |
| кнопки со стрелкой ↗ | кнопки «это ИИ / это Эли», поле ввода |
| светящийся шар «Твои навыки после практикума» | мягкий glow на фоне |

## Приёмы, из которых собран уровень
- Появление ставится на секунду слова: смотри `IN(el,t,23.8)` против `расшифровка.txt`.
- Внутри длинной фразы кадр меняется каждые 1–1.5 сек (сцены 46.8 и 60.3 — пример фаз через `out:`).
- В каждом кадре что-то живёт: мигают глаза робота, бегут частицы, дышит hero.
- Акцент только один на кадр. Посмотри по контакт-листу: красное везде одной деталью.
