# design-team-standards

Скилл-гид для команды дизайнеров студии. Содержит стандарты качества, правила работы с медиа, цветовые системы и чеклист перед сдачей.

## Использование
Добавь в свой .claude/CLAUDE.md:
```
Загружай скилл design-team-standards при работе с любым HTML/CSS/React кодом.
```

Или вызывай вручную: `/design-team-standards`
