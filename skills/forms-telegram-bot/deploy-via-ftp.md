# Деплой формы на хостинг через FTP (пример — Beget)

## Шаг 1. Создать отдельный FTP-аккаунт

⚠️ **Никогда не давай главный пароль хостинга** для FTP-доступа. Создавай отдельный аккаунт для каждой задачи.

1. Зайди в панель хостинга (в Beget: **Хостинг** → **FTP**)
2. Логин: например `LOGIN_forms` (латиница/цифры)
3. Пароль: пусть панель сгенерирует сама
4. **Путь к директории**: выбрать конкретную папку, например `/example.com/public_html/`
5. SSH **не включать**
6. Нажать **Добавить**

⚠️ В Beget подчёркивание в логине только **между буквами**, не в начале и не в конце.

## Шаг 2. Залить файл через curl

```bash
FTP_HOST="LOGIN.beget.tech"      # твой FTP-хост из панели хостинга
FTP_USER="LOGIN_forms"           # отдельный FTP-логин из шага 1
read -rs -p "FTP-пароль: " FTP_PASS; echo   # пароль вводится руками, в файлы его не пиши

# Создать папку (если нужна)
curl -s --user "${FTP_USER}:${FTP_PASS}" "ftp://${FTP_HOST}/" -Q "MKD forms"

# Залить файл
curl -s --user "${FTP_USER}:${FTP_PASS}" \
  -T /path/to/anketa.html \
  "ftp://${FTP_HOST}/forms/index.html"

# Проверить что залилось
curl -s --user "${FTP_USER}:${FTP_PASS}" "ftp://${FTP_HOST}/forms/" --list-only
```

## Шаг 3. Учесть проксирование домена

### Проблема: основной домен проксируется на Tilda

Если основной сайт (`example.com`) отдаётся **не напрямую с хостинга**, а проксируется на Tilda (например, через ddos-guard), то файл, положенный на хостинг в папку `example.com/public_html/forms/index.html`, снаружи по адресу `https://example.com/forms/` **не откроется** (404).

### Решения

#### Вариант А: технический домен хостинга
URL вида `https://LOGIN.beget.tech/example.com/forms/`

Минусы: длинный некрасивый URL.
Плюсы: работает мгновенно.
Для красивого URL — короткая ссылка через clck.ru / vk.cc.

#### Вариант Б: поддомен
1. Панель хостинга → **Домены** → добавить поддомен `forms.example.com`
2. Хостинг сам пропишет DNS и создаст папку
3. Залить файл в папку поддомена
4. URL: `https://forms.example.com` — красивый и работает

Минусы: 5 минут на создание + 5–10 минут на распространение DNS.
Плюсы: солидный URL для постов и рассылок.

#### Вариант В: другой домен
Если есть другой свободный домен — кладём туда, адрес вида `another-domain.ru/anketa/`.

## Шаг 4. Проверить что страница живая

```bash
curl -s -I "https://путь/к/странице/" -w "HTTP: %{http_code}\n"
```

Если 200 — всё ок.
Если 404 — папка не дошла до публичного веб-сервера, проверь путь и проксирование.

## Связь с Tilda

Если домен идёт через Tilda, **прямой деплой статичного HTML под основным доменом не работает**. В этом случае:
- либо переносим форму **в саму Tilda через T123/Zero Block**;
- либо используем **поддомен** или **другой домен**.
