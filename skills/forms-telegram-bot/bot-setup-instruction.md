# Как создать Telegram-бот для формы (5 минут)

## Шаг 1. Создать бота через BotFather

1. Открой Telegram → в поиске сверху набери **@BotFather** → перейди в чат
2. Отправь команду: `/newbot`
3. **Имя бота** (видно людям): например «Моя школа — Анкеты»
4. **Username бота** (для поиска): обязательно заканчивается на `_bot`. Например: `myschool_forms_bot`
5. BotFather пришлёт сообщение с **токеном** — длинная строка типа:
   ```
   1234567890:ЗДЕСЬ_БУДЕТ_ДЛИННАЯ_СТРОКА_ИЗ_БУКВ_И_ЦИФР
   ```

⚠️ **Токен секретный.** Не выкладывай в публичных репозиториях. Если случайно утёк — у BotFather команда `/revoke` → выбрать бота → получить новый токен.

## Шаг 2. Нажать /start у своего бота

1. В поиске Telegram найди бота по username (например `myschool_forms_bot`)
2. Нажми **Start** или отправь `/start`
3. **Сразу отправь** любое сообщение, например `тест` или `привет`

⚠️ **Это критично.** Telegram не даёт боту писать первым — только в ответ. После `/start` Telegram «открывает канал», и теперь бот может слать тебе сообщения через API.

## Шаг 3. Получить chat_id

### Способ А: через @userinfobot (самый простой)

1. В поиске Telegram найди **@userinfobot**
2. Нажми Start
3. Бот сразу пришлёт твой ID — это и есть chat_id

### Способ Б: через getUpdates API

1. Открой в браузере (замени `{TOKEN}` на свой):
   ```
   https://api.telegram.org/bot{TOKEN}/getUpdates
   ```
2. В JSON-ответе найди:
   ```json
   "chat":{"id": 123456789, ...}
   ```
   Числа в `"id"` — это chat_id

⚠️ **Если ответ `"result":[]`** — пустой массив. Значит ты ещё не нажала /start у бота или Telegram уже удалил старые updates (24 часа). Напиши боту ещё раз — обновится.

## Шаг 4. Подставить в HTML

В HTML-файле формы найди строки:
```js
const TG_BOT_TOKEN = "YOUR_BOT_TOKEN";
const TG_CHAT_ID   = "YOUR_CHAT_ID";
```

Замени `YOUR_BOT_TOKEN` и `YOUR_CHAT_ID` на свои значения **только в той копии файла, которую выкладываешь на сайт**.
Не сохраняй файл с настоящим токеном в git, в общий репозиторий или в папку скилла. Помни: во фронтенд-форме токен виден любому в исходном коде страницы — для серьёзных форм используй серверный прокси (см. `SKILL.md`).

## Шаг 5. Опционально — оформить профиль бота

В @BotFather:
- `/setdescription` — описание (видно в профиле бота)
- `/setabouttext` — короткий текст для профиля
- `/setuserpic` — аватарка
- `/setname` — изменить имя
- `/deletebot` — если хочешь удалить

## Шаг 6. Тестовая отправка

В терминале (замени TOKEN и CHAT_ID):
```bash
curl -s "https://api.telegram.org/bot{TOKEN}/sendMessage" \
  -d "chat_id={CHAT_ID}" \
  --data-urlencode "text=Тест связи! Бот работает."
```

Должно прийти сообщение в Telegram. Если пришло — всё настроено правильно.
