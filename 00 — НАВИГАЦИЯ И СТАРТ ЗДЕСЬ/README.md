# 00 — Навигация и старт здесь

Это публичная часть библиотеки Эли Аноры. Каждый раздел собран по типу задачи, а не по инструменту: так легче сразу найти нужный результат.

## Как выбрать скилл

- Нужен Reels, субтитры, SVG или типографика — иди в `01`.
- Нужен сайт, интерфейс, дизайн-система или арт-дирекция — в `02` и `03`.
- Нужны изображения или видео через AI — в `04`.
- Нужна форма или Telegram-бот — в `06`.
- Нужны правила работы в Claude Code — в `08`.

## Как установить

1. Открой папку конкретного скилла.
2. Скачай её вместе со всеми вложенными файлами.
3. Перетащи папку в Claude Code.
4. Напиши: «Установи этот скилл и кратко расскажи, когда ты будешь его применять».

Не перетаскивай в Claude Code всю библиотеку сразу: лучше подключать только скиллы под текущую задачу.
