# 📖 Экскурсия по моим скиллам Claude Code

Привет 🤍 Это все скиллы которые я использую в работе. Скилл в Claude Code — это папка с инструкцией, которую Claude автоматически подключает под свою задачу и работает по твоим правилам, а не по дефолту.

## Как это работает

1. Скачиваешь скилл (папку целиком)
2. Кладёшь в `~/.claude/skills/имя-скилла/`
3. Claude сам его находит и подключает, когда задача подходит по описанию

**Все папки должны содержать файл `SKILL.md` — в нём инструкция для Claude.**

## 🌟 Мои личные скиллы (Эли)

Мои собственные разработки. Забирайте:

### `eli-voice-skill`
**Что делает:** пишет тексты моим голосом — посты, сторис, рассылки, лендинги.
**Когда включается:** когда нужно написать пост или контент «в стиле Эли».
**Внутри:** правила голоса, разрешённый словарь, анти-паттерны, эталонные посты 2024 года, пары «до/после».

### `brandbook-camp-skill`
**Что делает:** держит фирменную систему Дизайн Кэмпа — палитра, программа, инструменты, слоганы.
**Когда включается:** любой контент про Дизайн Кэмп (посты, лендинги, презентации).
**Как использовать вместе с eli-voice:** для поста от лица Эли про Кэмп — комбинируй оба.

### `forms-telegram-bot-skill`
**Что делает:** создаёт HTML-форму на сайте которая отправляет заявки в Telegram-бота.
**Когда включается:** нужно сделать форму заявки/анкету/подписку с юр. согласиями (152-ФЗ).
**Внутри:** готовые шаблоны Tilda и standalone, инструкция настройки бота, деплой через FTP, блок юр. согласий.

## 🎨 Дизайн и UI (11 скиллов)

Разные почерки для сайтов и интерфейсов.

### `impeccable`
**Что делает:** главный скилл для любого дизайна интерфейса. Аудит, доработка, полировка UI.
**Когда включается:** «сделай лучше», «отполируй», «переделай», «покритикуй мой сайт».
**Ставь в первую очередь если задача про UI — этот скилл калибрует масштаб работы.**

### `high-end-visual-design`
**Что делает:** учит Claude делать сайты уровня агентства премиум-класса.
**Стиль:** дорогая типографика, спокойные цвета, тонкие анимации.
**Против:** дешёвых AI-паттернов, которые выдают «сгенерированный» вид.

### `dizayn-futuristik`
**Что делает:** футуристичные лендинги и hero-секции уровня Awwwards / Apple / Linear.
**Стиль:** тихая дорогая типографика, микро-анимации, видео-фоны со скроллом, диаграммы вместо цифр.
**Мой любимый для сайтов Кэмпа и роботов.**

### `minimalist-ui`
**Стиль:** редакторский минимализм. Тёплый монохром, типографический контраст, плоские бенто-сетки, приглушённые пастели. Без градиентов и теней.

### `industrial-brutalist-ui`
**Стиль:** промышленный брутализм. Швейцарская типографика + военный терминал. Жёсткая сетка, контрастный тайп, аналоговый шум.
**Для:** дашбордов, портфолио, эдиториал-сайтов.

### `emil-design-eng`
**Что делает:** философия Эмиля Ковальски о деталях которые делают софт приятным. Полировка компонентов, анимации, невидимые нюансы.

### `design-taste-frontend`
**Что делает:** архитектура интерфейса на уровне senior UI/UX инженера. Метрические правила, компонентная архитектура, hardware acceleration в CSS.

### `gpt-taste`
**Что делает:** редакторская вёрстка + продвинутая моушен-анимация GSAP.
**Внутри:** правило AIDA-структуры, широкая типографика (запрет 6-строчных абзацев), GSAP ScrollTriggers.

### `stitch-design-taste`
**Что делает:** генерирует DESIGN.md для Google Stitch — премиум-стандарты дизайн-системы (типографика, цвет, асимметричные лейауты, микро-моушен).

### `redesign-existing-projects`
**Что делает:** апгрейд существующих сайтов до премиум-качества. Аудит текущего дизайна, поиск дженерик-паттернов, замена без ломания функционала.

### `design-team-standards`
**Что делает:** продакшн-качество, стандарты дизайн-команды.

## 🎬 Генерация изображений (6 скиллов)

### `nano-banana-imagegen` ⭐
**Что делает:** промпт-инженерия для Nano Banana (Google Gemini 2.5/3 Flash Image).
**Когда включается:** фотореалистичный портрет, нейрофотосессия, предметка, замена фона, перенос стиля, сохранение лица модели.
**Важно:** НЕ для Midjourney/DALL-E — там своя логика (теги, веса), она в Nano Banana ломает результат.

### `kling-video`
**Что делает:** промпт-инженерия для Kling 3.0 — создание видео, оживление фото, настройка камеры и стиля.
**Внутри:** готовые шаблоны, настройка аудио.

### `brandkit`
**Что делает:** генерация премиум-бордов брендинга — гайды, логотипы, идентити-деки, визуальные миры.
**Стили:** минимализм, кино, эдиториал, dark-tech, лакшери, культура, безопасность, гейминг, dev-tools, consumer-app.

### `imagegen-frontend-web`
**Что делает:** генерация референс-картинок для сайтов. Одна секция = одна отдельная картинка (лендинг из 8 секций = 8 картинок, не в одном коллаже).

### `imagegen-frontend-mobile`
**Что делает:** генерация экранов мобильных приложений в рамке айфона. iOS/Android/кросс-платформа.

### `image-to-code`
**Что делает:** превращает картинку сайта в код. Сначала генерирует чистые картинки секций, потом собирает код 1-в-1.

## 📥 Как передать это ученикам

Вариант 1 — **архив папки**. Заархивируйте всю папку `Скиллы/` в zip и отправляйте. Ученик распаковывает, копирует папки в `~/.claude/skills/`.

Вариант 2 — **каждый скилл отдельно**. Ученик берёт только тот скилл, который ему нужен под задачу.

**Куда класть:** `~/.claude/skills/имя-скилла/` (или `.claude/skills/` внутри проекта — тогда скилл работает только в этом проекте).

**Проверка:** `SKILL.md` должен лежать в корне папки скилла. Если положил вложенно — Claude не найдёт.

## 🎯 Как я использую это в работе

**Для сайта Кэмпа/Роботов/личного:**
1. Загружается `impeccable` — калибрует масштаб

4. При необходимости — `imagegen-frontend-web` для генерации референсов

**Для контента:**
1. `eli-voice-skill` — мой голос
2. `brandbook-camp-skill` — если про Кэмп
3. `nano-banana-imagegen` — генерации фото

**Для персонажа Рокси в видео:**
1. `roxy` — параметры персонажа
2. `nano-banana-imagegen` — генерация кадров
3. `kling-video` — оживление в видео
