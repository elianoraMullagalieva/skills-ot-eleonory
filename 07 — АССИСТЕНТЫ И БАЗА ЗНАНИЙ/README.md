# 07 — Ассистенты и база знаний

Раздел зарезервирован для ассистентов, инструкций и баз знаний. Рабочие версии остаются приватными: они могут содержать клиентский контекст, внутренние документы и персональные данные.

В публичный репозиторий будут попадать только специально подготовленные, обезличенные шаблоны.
