# 🪶 Скилл «Голос Эли» (eli-voice)

Используется для написания и редактирования любого контента от лица Эли (elianora): посты в TG, сторис Inst, рассылки, описания продуктов, лендинги.

## Файлы

- **`SKILL.md`** — главный файл со всеми правилами голоса, словарь, ритм, анти-паттерны, чек-лист
- **`examples.md`** — 5 эталонных постов из реальных публикаций Эли 2024 года
- **`before-after.md`** — пары «стерильно → голос Эли» для калибровки

## Как использовать

### Если ты — Эли:
Просто скажи «напиши пост про X в моём стиле» или «перепиши это в моём голосе» — Claude автоматически подтянет этот скилл из папки.

### Если ты — Claude:
Прочитай `SKILL.md` целиком и `examples.md` хотя бы выборочно перед написанием. Перед отдачей текста — пройди по чек-листу из `SKILL.md`.

## Когда обновлять скилл

После каждых 5–10 написанных постов вместе с Эли:
1. Если её правки повторяются (одно и то же исправляет) — добавь правило в `SKILL.md`
2. Если есть особенно удачный пост, который она утвердила — добавь в `examples.md`
3. Если поймал хорошую пару «до/после» — добавь в `before-after.md`

Скилл — **живой**. Чем больше работаем, тем точнее становится голос.

## Связь с другими скиллами

Этот скилл = только **голос Эли**. Фактическая информация о её продуктах живёт в отдельных скиллах:

- **`brandbook-camp-skill/`** — Дизайн Кэмп (палитра, программа, оценка, инструменты)
- В будущем: `brandbook-academy-skill/` для Академии Дерзай в Дизайн
- В будущем: другие продуктовые скиллы

**Когда писать пост про Кэмп от лица Эли:** комбинируй два скилла — `eli-voice-skill/` (голос) + `brandbook-camp-skill/` (факты).
