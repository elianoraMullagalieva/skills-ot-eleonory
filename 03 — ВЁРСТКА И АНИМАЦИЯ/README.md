# 03 — Вёрстка и анимация

- `Вёрстка/frontend-design` — создание выразительных production-ready интерфейсов.
- `Анимация/animejs` — timeline-анимация HTML, CSS, SVG и JavaScript-объектов.

Сначала собирай структуру и адаптив, затем добавляй движение. Анимация должна объяснять интерфейс, а не мешать чтению.
