# 02 — Дизайн и чувство вкуса

Раздел для интерфейсов, визуальной системы и арт-дирекции. Все 11 навыков лежат в `Скиллы дизайн и UI`.

- `design-taste-frontend`, `emil-design-eng`, `high-end-visual-design` — визуальное качество и детали интерфейса.
- `design-team-standards`, `impeccable`, `redesign-existing-projects` — стандарты, аудит и улучшение существующего проекта.
- `dizayn-futuristik`, `industrial-brutalist-ui`, `minimalist-ui` — конкретные визуальные направления.
- `gpt-taste`, `stitch-design-taste` — системная работа с дизайном и промптами.

Подключай один основной стилевой скилл и при необходимости один скилл для аудита — не все сразу.
