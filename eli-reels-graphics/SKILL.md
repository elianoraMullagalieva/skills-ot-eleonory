# Скилл: графика Reels Эли

Это ТЗ появилось потому, что раньше каждый кусок делался на глаз → разнобой размеров, куча жирностей, всё по центру в 3 строки, «ужасно и некрасиво». Здесь — жёсткие правила. Следуй им дословно. Если хочется отступить — не отступай, лучше упрости.

## 0. Что делаем
Анимация-подложка кодом (HTML + anime.js), рендер в mp4 через `~/.claude/skills/animejs/record.py`, ложится в CapCut ЗА говорящую голову. Холст **1080×1920**. Вся графика строго в **верхних 1040px** (`.safe{height:1040px}`) — низ занят видео Эли (лицо высоко в кадре).

Рендер: `python3 ~/.claude/skills/animejs/record.py --html X.html --out Y.mp4 --duration N`
Проверка ПЕРЕД показом: вытащить кадры через ffmpeg, собрать контактный лист, посмотреть Read'ом. Никогда не показывать невиденное.

## 1. ЖЁСТКАЯ типографика (нарушение = переделка)

**Шрифт — только Manrope.** Один шрифт на весь ролик. JetBrains Mono разрешён ТОЛЬКО для углового декора `.mono` (мелкие подписи `claude code · skills`, `[100k+]`). Больше нигде.

**РОВНО 3 размера текста. Задаются CSS-переменными, брать ТОЛЬКО из них:**
```css
--t-hero: 150px;  /* главная мысль кадра. 1 на кадр. */
--t-mid:  64px;   /* подзаголовок / вводная строка */
--t-cap:  40px;   /* подпись, детали, роли, углы */
```
Никаких `font-size` вне этих трёх. Если «нужен ещё один размер» — значит кадр перегружен, убери элемент.
Hero можно локально ужать (напр. длинное слово «требованиями») — но в диапазоне 110–150px, не мельче mid.

**РОВНО 2 жирности:**
```css
700 (Bold)  — hero и выделенное слово
300 (Light) — mid, cap, всё вторичное
```
НИКАКИХ 400/500/800 вперемешку. Контраст строится размером + цветом, НЕ пятой жирностью.

**Один шрифт на строке.** Не мешать Manrope+другой в одной строке (JetBrains только в углах).

## 2. ЦВЕТ (монохром + точечный терракот)
```css
--bg1:#f4f5f3; --bg2:#eaebe9;   /* холодный off-white, НЕ тёплый беж */
--ink:#1a1c1b;                   /* графит — весь основной текст */
--mut:#a3a8a2;                   /* серый — вторичный текст */
--accent:#c96442;                /* терракот */
--dark:#141615;                  /* тёмные сцены (терминал/инверсия) */
```
- Все **заголовки — чёрные** (`--ink`).
- Терракот `--accent` — СМЫСЛОВОЙ маркер «тут про Claude / ключевой акцент». Точечно: ОДНА деталь на кадр (счётчик, одно слово, точка-акцент, искра ✦, иконка Claude). НЕ рамки/теги/кнопки/несколько слов.
- **Заголовок из 2+ слов НЕ красить в 2 цвета.** Либо весь чёрный, либо разбить на 2 слайда.
- **ЗАПРЕЩЕНО:** красный, зелёный, лайм, фиолетовый, синий. Дешёвые 2-стоповые градиенты. Эмодзи (только SVG-иконки тонкой линией).

## 3. ВЫРАВНИВАНИЕ (правило Эли: не центрировать многострочное как попало)
- **1 строка** → по центру, крупно (hero).
- **Вводная фраза** (mid) над контентом — короткая, 1 строка. Если не влезает — сократи текст, НЕ переноси на 3 строки по центру.
- **Отступ mid → крупное слово/контент — КОМПАКТНЫЙ (~24–32px)**, как в `claude mem`. Большой зазор (60px+) читается как «дыра» — Эли забраковала (15.07). Заголовок и его акцент — единая связка, не разносить.
- Никогда: абзац из 2-3 длинных строк, отцентрованный. Это выглядит дёшево.

### 3.1 Перечисления (3+ пунктов) — НЕ стопкой крупных слов
**ЗАПРЕЩЕНО:** 3+ крупных hero-слова стопкой по центру (дизайнерам / разработчикам / маркетологам крупно друг под другом). Это выглядит грязно и тяжело — Эли забраковала (15.07).
**ПРАВИЛЬНО — оформлять как ПУНКТЫ ТЕРМИНАЛА** (эталон — сцена `claude mem`):
- тёмное окно-терминал (`.win.term`, фон `--dark`, бар с 3 точками),
- каждый пункт — отдельная строка `› текст`, промпт `›` терракотовый, текст `--t-cap`/34px Manrope, серо-белый,
- строки появляются по одной (fade+translateX), можно с печатью (typeRow).
Это единый «фирменный» приём для любых списков (роли, свойства, пункты памяти). Крупным hero-размером — только 1-2 акцентных слова, НЕ список.
- Список из 1-4 коротких слов-акцентов (вкус·видение·требования) допустим по одному на строку hero-размером ТОЛЬКО если их ≤2 в кадре одновременно (предыдущие гаснут). Иначе — терминал-пунктами.

## 4. КОМПОЗИЦИЯ
- **Воздух обязателен.** Между блоками большой отступ. Лучше убрать элемент, чем сжать воздух.
- **Жёсткое центрирование:** контейнер фиксированной ширины 1080px, `align-items:center`. Число — `tabular-nums`, чтобы не дёргалось при счёте.
- Фазы одной сцены (напр. «фаза1 → фаза2») — абсолютно наложены (`position:absolute`), а не в потоке flex (иначе скрытая фаза сдвигает центр).
- Угловой декор `.mono` — всегда: `tl` = `claude code · skills`, `tr` = `[ 100k+ ]`.

## 5. «ИНТЕРЕСНО» — обязательный чек-лист для каждого куска
Эли: «если прошу кусок — сделай его интересно, а не просто текст». Кусок ГОТОВ, только если выполнены ВСЕ 4:

1. **Инфографика/схема, а не голый текст.** Мокап, терминал (печатает строки), список с галочками, полоски-бары, стрелки-связи, лента, счётчик. Визуальная метафора смысла.
2. **Живое движение.** Объекты летят / собираются / трансформируются / печатаются — не просто fade-in→fade-out. Приёмы animejs: spring-easing, stagger, strokeDashoffset, morphing, счётчик-набегание.
3. **Одна мысль = один кадр.** Чёткая смена сцен. Не валить всё в кучу. Каждая сцена доносит ровно одну вещь.
4. **Метафора/образ.** Не «подпись к слову», а визуальная идея: папка со скиллами, звёзды github, терминал-диалог, лента примеров.

Если кусок — это просто текст, который появился и исчез → он НЕ готов. Добавь минимум инфографику + движение.

## 6. АНТИ-ЗАСТЫВАНИЕ
Кадр должен ЖИТЬ всю длину фразы. Если фраза длиннее анимации — НЕ оставлять статику. Добавить микродействие: дыхание (`scale:[1,1.03,1]` / `translateY:[0,-10,0]` loop, easeInOutSine), пульс акцента, довыезд детали. Пустой стоящий кадр = брак.

## 6.1 ТЕМП — динамично, без долгих появлений
Эли монтирует куски в тайминг речи — они должны быть ЖИВЫЕ, не тягучие. Дефолт:
- Появление элемента: **350–450мс** (не 550–700).
- Печать typeRow: **20–24мс** на символ (не 30–34).
- Удержание сцены перед сменой: **~1400мс** для сцены с чтением (терминал), **~400мс** для короткой.
- Смена фазы: **~350мс**.
Ориентир: сцена из 3 фаз должна укладываться в ~11 сек. Если Эли просит «влезть в N секунд» — режь удержания и длительности, НЕ выбрасывай смыслы.
Раздутое пульсирование (`scale` с большой амплитудой, зациклено на весь кадр) = «грязно», Эли забраковала. Дыхание — едва заметное (амплитуда ≤8px / ≤1.04 scale), одно на кадр.

## 7. ПАЙПЛАЙН ПОД ОЗВУЧКУ
whisper (`mlx-whisper`, модель `whisper-large-v3-turbo`, PATH `~/Library/Python/3.9/bin`) транскрибирует речь → раскладываю сцены по таймкодам (массив `[start_sec, sceneId]`), НЕ по фиксированным HOLD. Синхрон делается ПОСЛЕ утверждения стиля. Финал: анимация сверху (непрозрачна, верх ~1000px) + видео Эли снизу, собирается ffmpeg-overlay.

## 8. СТАРТОВЫЙ ШАБЛОН
Каждый новый кусок начинать копией `template.html` из этой папки — там уже вшиты переменные размеров/цветов, `.safe`, угловой декор, fit(), хелперы typeRow/counter. Не изобретать структуру заново.
