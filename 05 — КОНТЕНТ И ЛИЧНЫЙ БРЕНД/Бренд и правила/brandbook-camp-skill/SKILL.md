# Брендбук Дизайн Кэмпа

Это **отдельный скилл для продукта Дизайн Кэмп**. Не смешивать с личным голосом Эли (это в `eli-voice-skill/`) и не смешивать с другими брендбуками Эли (Дерзай в Дизайн, будущие продукты).

## Когда использовать

- Любой контент про Дизайн Кэмп — посты в чат, в TG-канал, в Inst
- Лендинги Кэмпа (текущая бесплатная версия и платный Кэмп 2.0)
- Презентации, материалы лекций, обложки в YouTube/ВК
- Визуальные ассеты (баннеры, превью, превью видео)
- Email-шаблоны и сообщения участникам

## Когда НЕ использовать

- Личные посты Эли в её канале (это `eli-voice` без брендбука Кэмпа)
- Материалы Академии «Дерзай в Дизайн» (это её отдельный бренд)
- Любые другие продукты Эли в будущем (для каждого продукта будет свой скилл)

## Основное содержание

См. файл **`BRANDBOOK.md`** в этой папке — там вся фирменная система:
- Палитра (чёрный + неон-лайм `#C6F33A` + белый)
- Типографика (жирный гротеск, крупные заголовки)
- 3 правила кейса (Логика / Креатив / Аккуратность)
- Программа из 4 этапов (01–04)
- Фирменная нумерация `{01}{02}{03}` для домашки
- Слоганы со слайдов
- Актуальный список инструментов

## Как использовать вместе с eli-voice

Когда пишешь пост ПРО Дизайн Кэмп **от лица Эли**:
1. Сначала открой и применяй `eli-voice-skill/SKILL.md` — это её **голос**: ритм, слова, словарь, анти-паттерны
2. Затем накладывай этот скилл — фактическая информация про продукт: программа, оценка, инструменты, слоганы

То есть: **голос Эли × факты Кэмпа = пост про Кэмп от Эли**.

## Архитектура папки

```
brandbook-camp-skill/
├── SKILL.md          ← этот файл (метаданные, когда использовать)
├── BRANDBOOK.md      ← вся фактическая информация (палитра, программа, инструменты)
└── README.md         ← инструкция по использованию
```
