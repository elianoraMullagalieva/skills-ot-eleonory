# Брендбук Дизайн Кэмпа — фирменная система

Загружено из слайдов брендбука 23.06.2026. Используй эти материалы для любого визуального и текстового контента про Кэмп.

## 🎨 Палитра

- **Чёрный**: `#000000` — основной текст, фон акцентных блоков
- **Неон-лайм**: `#C6F33A` (примерно) — фирменный акцентный цвет Кэмпа, выделяет КРЕАТИВ-блок
- **Белый**: `#FFFFFF` — фон по умолчанию
- **Серый-граница**: тонкие линии прогресс-бара (`#E5E5E5` или светлее)

Не использовать: пастельные цвета, градиенты, мягкие тона. Дизайн-Кэмп = брутальный неон + чёрный.

## ✍️ Типографика

- **Шрифт заголовков**: жирный гротеск с круглыми буквами (визуально похож на Druk, Suisse International Bold, TT Hoves Bold)
- **Размер заголовков на слайдах**: огромный, на половину экрана
- **Контраст**: крупный заголовок vs очень мелкий поясняющий текст
- **Логотип Кэмпа**: «Дизайн Кэмп» в две строки, окружён звёздочками-орнаментом ❋

## ⚖️ Критерии оценки кейса — «3 правила кейса, который работает 24/7»

Это **фирменная оценочная система Эли**. Каждое правило по шкале 1–10:

1. **Логика 1–10** — Смыслы, интуитивно понятная структура
2. **Креатив 1–10** — Идея и уникальность (выделено лаймом — самое важное)
3. **Аккуратность 1–10** — Композиция, размеры, отступы, выравнивания, пропорции

При оценке любой работы — называй цифру по каждому из трёх + общая 1–10. Это и есть **язык оценки Кэмпа**.

## 📅 Программа Кэмпа — фирменная структура из 4 этапов

Это слайд «Как мы набиваем руку на кэмпе». Используй именно эти слова, не переписывай:

**01 · Идея и черновик**
- выбираем напарника
- выбираем направление
- собираем мудборд
- делаем черновик

**02 · Первый батл**
- созваниваетесь с напарником
- каждый реализует свою идею за 1 час (1 экран)
- отправляете работу на конкурс
- получаете фидбек

**03 · Собираем дизайн**
- генерируем фото, видео для фонов
- используем Figma MCP
- собираем дизайн-проект

**04 · Верстаем и оживляем**
- Верстаем с Claude
- Анимируем

## 📋 Домашка перед батлом

Стандартная триада с фирменного слайда «Домашка»:

```
{01}  Найти напарника
{02}  Выбрать тему
{03}  Собрать анимированный мудборд на Awwwards
```

Нумерация в фигурных скобках `{01} {02} {03}` — это **фирменная нумерация Кэмпа** на слайдах.

## 🎯 Слоганы со слайдов

- «3 правила кейса, который работает 24/7» — оценочный слоган
- «Как мы набиваем руку на кэмпе» — программа в одну фразу
- «Домашка» — задания до батла

## How to apply

При написании любого контента про Кэмп:
- Если описываешь программу — используй точные формулировки со слайдов (01/02/03/04, не «Идея/Концепт/WOW/Код»)
- Если упоминаешь оценку — называй 3 фирменные критерия с цифрами 1–10
- Если говоришь про дизайн-систему Кэмпа — используй неон-лайм и чёрный
- Если делаешь иллюстрацию текста — крупная типографика, минимум деталей, акцент лаймом


## 🛠 Инструменты Дизайн Кэмпа (актуальный список — 23.06.2026)

### Для идей и концептов
- Claude — главный мозг для брейншторма и брифа
- ChatGPT — вторая голова, плюс GPT-картинки для быстрых набросков
- Gemini — большой контекст, разбор длинных брифов

### Для визуала и ассетов
- Midjourney — мудборд, стиль, атмосфера
- Nano Banana / Gemini Flash Image — быстрая генерация и редактирование
- Flux — продакшен-уровень фото-генерации
- Higgsfield — motion control, эффекты, нейрофотосессия
- Syntex — нейрофотосессия, работа с реальными фото
- Magnific и Krea — апскейл и стилизация ассетов
- Seedream — мудборды и редактирование фото от ByteDance
- Soul 2.0 — фотореалистичная генерация от Higgsfield

### Для видео и моушена
- Seedance — новая модель видео от ByteDance
- Runway — видео и моушен для героев
- Kling AI — кинематографические ролики
- Pika — короткие анимации блоков
- Veo 3 — Google, если есть доступ

### Для дизайна и переноса в код
- Figma — основной макет
- Figma MCP — быстрый перенос концепта в Figma из ИИ-генерации

### Для вёрстки и кода
- Claude Code — наш основной инструмент
- Cursor — альтернатива для тех, кто привык к VS Code
- Codex CLI и OpenAI Codex — аналог Claude Code от OpenAI

**Правила использования при написании контента:**
- Не добавляй инструменты, которых нет в этом списке. Soul 2.0 — это модель от Higgsfield (не путать с Sora от OpenAI, которую мы НЕ используем). Seedance ≠ Seadence
- Не упоминай Perplexity, Adobe Firefly, Bolt, Lovable, v0, ElevenLabs, Suno — Эли их не использует в Кэмпе
- Группировка: идеи / визуал / видео / дизайн / код — не смешивать
