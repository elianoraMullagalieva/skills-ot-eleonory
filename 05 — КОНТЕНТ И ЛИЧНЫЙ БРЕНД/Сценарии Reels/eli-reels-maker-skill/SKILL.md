## Часть 2. Голос Эли (быстрая версия)

Полный скилл голоса — в `eli-voice-skill/SKILL.md`. Здесь — самое важное для Reels.

### Приоритетные живые слова

✅ Используй активно:
- «обалдела / выпала / в шоке» (про эмоцию)
- «зашло / не зашло» (про реакцию)
- «шикарно / шикарный / круто / огонь / бомба / топ»
- «вывозить / не вывозила» (про нагрузку)
- «терпила / терпило» (про слабую позицию в прошлом — только про себя)
- «бабки» (про деньги — только в TG, НЕ в Instagram!)
- «жопа / горящая жопа» (про стрессовую ситуацию — только в TG!)
- «дамы, девочки, дорогая» (тёплое обращение)
- «по-крупному, играть по-крупному» (амбиции)

### Запрещено

❌ Не пиши:
- «охренела / хрен / нифига» — слишком грубо, Эли выросла
- «полная задница» — использует «жопа», но не это
- Мат, даже завуалированный
- Длинные тире `—` (em-dash) → только короткие `-`
- Двойные пробелы

❌ Инфобизнес-паттерны (Эли их ненавидит):
- «Друзья», «Дорогие мои», «Сегодня поговорим о...»
- «Хочу рассказать вам про...»
- «Не упусти шанс», «Записывайся», «Жми кнопку»
- «Переходи по ссылке прямо сейчас»
- Рваные обрывки в 1-2 слова на отдельной строке («Серьёзно.», «И всё.», «Точка.»)
- 🚀💪🔥💯⭐️ (затёртая инфобизнес-классика)

### Разрешённые эмодзи

🤍 (белое сердце — фирменное) · 🦋 · ⚡ · 🌱 · 🌀 · 🌿 · ✌🏼 · 🎁 · 🥁 · 💸

**Правило:** 1-3 эмодзи на весь сценарий. Не больше.

### Ритм — «один-один-два»

```
Короткая фраза.
Короткая фраза.
Раскрытие на 1-2 предложения.
```

Не рубленые обрывки. **Полноценные предложения**, но короткие абзацы.

## Часть 3. Instagram-табу (КРИТИЧНО)

Instagram блокирует слова про деньги, продажи, работу. Reels с этими словами получают в 5-10 раз меньше охватов + shadow ban.

### Запрещено писать прямо в Reels для Instagram

- деньги, заработать, доход, прибыль
- купить, продать, продажа, цена, стоимость, оплата
- млн, тыс, рублей, долларов, $, ₽
- «клиент», «продвижение» — иногда режет

### Безопасные замены

| Запрещённое | Замены |
|---|---|
| деньги / бабки | результат, кэш, «X», отдача, выхлоп |
| заработать | прийти к результату, выйти на новый уровень |
| доход / прибыль | приход, отдача, цифры |
| продать | передать ценность, отдать в хорошие руки |
| цена | условия, инвестиция, что внутри |
| 100 000 ₽ | «шестизначные цифры», «100к» (иногда пропускает) |
| миллион | «семизначный приход», «1М», «миллик» |
| купи / запишись | переходи, приходи, отметься, напиши мне |

**В Telegram** — можно писать прямо. В IG — только заменами.

## Часть 4. Формат Reels (структура)

### Длина

**30-60 секунд** — оптимум для IG в 2026.
**7-15 секунд** — если хук + один тезис + один визуал (для взрыва охватов).
**60-90 секунд** — если разбор процесса (глубоко, но CTR ниже).

### Трёхчастная структура

**1. Крючок (первые 3 секунды)** — ОБЯЗАТЕЛЬНО.
Без крючка Reels не досмотрит никто. Первая фраза должна быть:
- Провокацией («Дизайнер, который не кодит — это дизайнер прошлого»)
- Обещанием («Собираю сайт за 2 минуты, смотри»)
- Разоблачением («Все думают, что Claude Code — это про программистов. Нет.»)
- Цифрой («Раньше делала за месяц, сейчас за 3 дня»)
- Вопросом («Знаешь почему твой сайт выглядит дёшево?»)

**2. Мясо (20-45 секунд)** — раскрытие тезиса.
Один тезис = один Reels. Не пытайся впихнуть 3 идеи. Показывай процесс, экран, результат.

**3. Мини-CTA (последние 3-5 секунд)** — обычно вопрос или мягкий призыв.
- «Сохрани если пригодится»
- «Подпишись если делаешь сайты»
- «Расскажи в комментах — пробовала уже?»
- «Ссылка на урок в шапке» (если есть)

### Что НЕ вставлять в CTA

- «Обязательно подпишись»
- «Не забудь поставить лайк»
- «Оставь коммент если понравилось»
- Всё что читается как «прошу тебя очень»

## Часть 7. Как сочетать экспертность и натуру

Это самая частая ошибка при написании Reels для Эли. Разбираю по правилам.

### Правило 1. Никаких «5 фактов о X»

**Плохо:** «5 вещей, которые я узнала работая с Claude Code»
**Хорошо:** «Одна ошибка, из-за которой мой первый сайт в Claude Code выглядел как из 2015»

Эли не пишет списки-советы. Она пишет **истории с одним инсайтом**.

### Правило 2. Экспертность через процесс, не через тезисы

**Плохо:** «Claude Code эффективнее Figma для быстрого прототипирования»
**Хорошо:** «Смотри что я сделала за 40 минут. Три года назад это было бы 2 недели с командой»

Показываешь → говоришь → доказываешь. Не наоборот.

### Правило 3. Натуру — только через конкретику

**Плохо:** «Иногда бывает сложно, но я справляюсь»
**Хорошо:** «Позавчера я снова заплакала над макетом. Клиент прислал 47 правок к hero. Знакомо?»

Эмоция через факты, не через абстракцию.

### Правило 4. Экспертность без «я лучше знаю»

Эли не говорит «я лучше знаю». Она говорит:
- «Я долго пробовала X — не сработало. Работает Y»
- «Три года назад делала как все. Стало страшно, попробовала иначе. Показываю разницу»

Экспертность подаётся **через опыт с провалами**, а не через «слушайте меня».

### Правило 5. Один Reels = один тезис + одна эмоция

Не пытайся впихнуть «экспертность + личную историю + вызов подписаться + промо продукта» в 60 секунд. Разбивай на 3 отдельных Reels.

## Часть 8. Антипаттерны (сразу отклоняю)

## Часть 10. Как работать с этим скиллом

### Когда Эли пишет «сделай 5 сценариев Reels про X»

1. Читай задачу целиком
2. Определи кластер (А/Б/В/Г/Д/Е)
3. Выбери 5 разных крючков из банка (или сгенерируй в стиле банка)
4. Для каждого сценария заполни шаблон
5. Проверь по чек-листу антипаттернов
6. Проверь Instagram-табу (если для IG)
7. Прочитай вслух — если звучит как инфобиз-эксперт, переписывай

### Когда Эли пишет «нарежь из моего часового урока 5 Reels»

1. Проси таймкоды исходника
2. Определи 5 самых мощных моментов (лайфхак / инсайт / визуал wow / провокация / результат)
3. Пиши сценарий каждой нарезки: короткий крючок + основной кусок из урока + мини-CTA
4. Указывай точные тайм-коды исходника из которых нарезать

### Когда Эли пишет «предложи темы для Reels на неделю»

1. Смешивай кластеры (не 5 обучалок подряд)
2. Идеал: провокация + процесс + обучалка + личное + до/после = 5 разных вайбов
3. Пиши только заголовки + крючки, полные сценарии — по запросу

## Часть 12. Финальный настрой
