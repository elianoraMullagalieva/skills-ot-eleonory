# 05 — Контент и личный бренд

Здесь будет публичная подборка скиллов для сценариев, голоса и персонажей. Сейчас раздел оставлен как навигационный: исходные материалы содержат личные данные, рабочие документы и контекст, который нельзя автоматически публиковать.

Когда появится обезличенная версия, она будет добавлена сюда отдельными папками с `SKILL.md`.
